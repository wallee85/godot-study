## 1. 创建项目

### 1.1 打开项目管理器

双击解压出来的 **`Godot_v4.7.2-stable_mono_win64.exe`**。

首次打开你会看到**项目管理器**（Project Manager）：

```
┌──────────────────────────────────────────────┐
│  项目列表（现在空的）            [新建项目]  │  ← 右上角
│                                              │
│                                  [导入]      │  ← 右上角
│                                  [扫描]      │  ← 右上角
└──────────────────────────────────────────────┘
```

### 1.2 点「新建项目」

点右上角的「**新建项目**（New Project）」，填这几项：

| 字段 | 填什么 | 说明 |
|---|---|---|
| **项目名 (Project Name)** | `DodgeTheCreeps` | 随便起，只是显示用 |
| **项目路径 (Project Path)** | 比如 `D:\Workspace\games\DodgeTheCreeps` | 点右边「浏览」选目录；**注意看下面的提醒** |
| **渲染器 (Renderer)** | 保持 **`Forward+`**（默认） | 2D 用不上高级特性，但它是默认且最完整，**不要动** |
| **版本控制元数据 (Version Control Metadata)** | `Git`（默认） | 会帮你生成 `.gitignore` 和 `.gitattributes`，**保持默认** |

> ⚠️ **路径里不要有中文和空格**。两个引擎（Godot、Unity）在这一条上一样敏感，中文路径可能引发导入或导出时的诡异问题。
> ✅ **推荐**：`D:\Workspace\games\DodgeTheCreeps`

点「**创建并编辑**（Create & Edit）」。

### 1.3 ✅ 检查点

创建成功后 Godot 会自动打开**编辑器主界面**，你会看到：

- 中间是空的灰色视口
- 最左上角写着项目名 `DodgeTheCreeps`
- 没有报错弹窗

> 如果弹出"是否要打开"之类的提示，选打开。

## 2. 认识编辑器界面（先认路，后面要反复用）

Godot 默认布局，**记住这 5 个面板的位置**：

```
┌──────────────┬────────────────────────────┬──────────────┐
│              │                            │              │
│ ① 场景       │  ③ 主视区                  │ ④ 检查器     │
│  (Scene)     │   2D / 3D / 脚本 / 游戏    │ (Inspector)  │
│  左上         │   四个标签页               │  右侧         │
│              │   中间                      │              │
├──────────────┤                            ├──────────────┤
│ ② 文件系统   │                            │ ⑤ 节点/历史   │
│ (FileSystem) │                            │              │
│  左下         │                            │  右中         │
├──────────────┴────────────────────────────┴──────────────┤
│ 底部：输出 / 调试器 / 音频 / 动画 / 着色器编辑器 / 精灵帧   │
└───────────────────────────────────────────────────────────┘
```

| 面板 | 中文名 | 作用 | 后面的用途 |
|---|---|---|---|
| ① | **场景** | 当前场景的**节点树** | 每章都在用 |
| ② | **文件系统** | 你项目目录里的所有文件（`res://`） | 找素材、拖模板 |
| ③ | **主视区** | 4 个标签：**2D**（摆位置）/ **3D** / **脚本**（写代码）/ **游戏**（运行画面） | 摆 UI、拖路径 |
| ④ | **检查器** | **选中节点的属性** | 改 `Scale`、`Color`、`Wait Time`… |
| ⑤ | **节点 / 历史** | 「节点」面板里有**信号列表** | 连信号（05、06 章） |

> **对照 Unity**：Unity 是 Hierarchy / Scene / Game / Inspector / Project / Console 六个**独立窗口**；Godot 把这些**塞进一个窗口**，用标签页切换。第一次会觉得挤，习惯之后效率更高（不用来回切窗口）。

**记两个快捷键**：

| 快捷键 | 作用 |
|---|---|
| **`F5`** | 运行**整个游戏**（主场景） |
| **`F6`** | 运行**当前打开的场景**（单独测试一个场景，非常常用） |

## 3. 导入素材

### 3.1 复制素材目录

打开你系统的**文件资源管理器**，找到本仓库：

```
d:\Workspace\games\study\godot\素材\
├─ art\
└─ fonts\
```

把 **`art`** 和 **`fonts`** 这**两个文件夹整个复制**到你刚建的项目目录下：

```
D:\Workspace\games\DodgeTheCreeps\        ← 你的项目目录
├─ project.godot
├─ .gitignore
├─ .godot\        （Godot 自动生成的缓存，别管它）
├─ art\           ← 复制过来
└─ fonts\         ← 复制过来
```

> **不用关掉 Godot**。Godot 会**自动检测到新文件**并导入（几秒钟）。
> **为什么直接复制文件夹就行**：Godot 里"项目根目录 = `res://`"，任何放进去的文件都能用，**不需要"添加资源"之类的操作**。

### 3.2 ✅ 检查点

回到 Godot，看**左下角的「文件系统」面板**：

1. 应该出现了 **`art`** 和 **`fonts`** 两个文件夹
2. 点开 `art`，应该看到 12 个文件：6 个敌人图、4 个玩家图、2 个音频
3. **点开 `art` 里的任意一个 `.png`，右下角会显示预览缩略图**（能看到图就说明导入成功）
4. `fonts` 里应该看到 `Xolonium-Regular.ttf`

> **注意**：你在文件系统面板里看到的**只有原始文件**（`.png` / `.wav` / `.ogg` / `.ttf`）。
> Godot 会在**磁盘上**为每个文件生成一个 `.import` 文件（比如 `playerGrey_walk1.png.import`），但**面板里不显示它们**——那些是导入设置，**不要手动改、不要删**。

**如果没看到文件**：

| 现象 | 原因 |
|---|---|
| 文件系统面板里没有 `art` | 复制到了错误的目录（比如复制到了 `DodgeTheCreeps\art\art`）→ 检查层级 |
| 有文件夹但里面是空的 | Godot 还没扫描完，等几秒，或菜单「项目 → 重新加载当前项目」 |
| 图能看见但显示成"?" | 导入失败，看底部「输出」面板的报错 |

## 4. 项目设置：分辨率 480 × 720

这是本章**最关键的一步**。

### 4.1 打开项目设置

菜单 **`项目 → 项目设置`**（Project → Project Settings）。

弹出的窗口**左侧是一竖排分类**，顶部有几个标签页（常规 / 输入映射 / 本地化 / 自动加载 / 着色器全局变量 / 插件）。

> **不用找"保存"按钮**：Godot 的项目设置**改了立即生效并自动保存**到 `project.godot`。关掉窗口就是保存。

### 4.2 设置视口尺寸

左侧点 **`显示 (Display) → 窗口 (Window)`**，在右侧找到：

| 设置项 | 改成 | 为什么 |
|---|---|---|
| **视口宽度 (Viewport Width)** | **`480`** | 官方原话：*"这个游戏是为**竖屏（portrait）**设计的，所以我们要调整游戏窗口的大小"* |
| **视口高度 (Viewport Height)** | **`720`** | 480×720 是个 2:3 的竖屏比例 |

> **这两个数字决定了"你的游戏世界里屏幕有多大"**，后面所有坐标都基于它：
> - 屏幕中心 = `(240, 360)`
> - 屏幕右边 = `x = 480`，屏幕下边 = `y = 720`
> - 玩家的移动边界、刷怪路径、UI 的位置，全都跟这两个数有关

### 4.3 设置拉伸模式

**还在同一页**，往下找（或展开）**`拉伸 (Stretch)`** 分组：

| 设置项 | 改成 | 为什么 |
|---|---|---|
| **模式 (Mode)** | **`canvas_items`** | 缩放整个画面，让游戏在不同大小的窗口里看起来一致 |
| **纵横比 (Aspect)** | **`keep`** | **保持 480:720 的比例**，四周加黑边，而不是把画面拉变形 |

官方原话（翻译）：

> 把 **Mode 设为 `canvas_items`、Aspect 设为 `keep`**，这样**游戏在不同尺寸的屏幕上缩放行为一致**。

**这两个设置的实际效果**：

| 你把游戏窗口拉成 | 会发生什么 |
|---|---|
| 更高更窄 | 画面按宽度缩放，上下加黑边 |
| **`Mode` 设成 `disabled` 会怎样** | 游戏永远是 480×720 一小块，放大窗口也没用 |
| **`Aspect` 设成 `ignore` 会怎样** | 画面被拉伸变形（圆形变椭圆） |

### 4.4 ✅ 检查点

| 检查项 | 怎么确认 |
|---|---|
| 视口是 480×720 | 「项目设置 → 显示 → 窗口」里能看到这两个数字 |
| 拉伸 Mode = `canvas_items` | 「显示 → 窗口 → 拉伸」分组里 |
| 拉伸 Aspect = `keep` | 同上 |

改完**关掉项目设置窗口**。设置会自动保存进 `project.godot`。

## 5. 要不要改"像素过滤"？（**官方素材不用改**）

如果你有 Unity 经验，可能会想找 `Filter Mode = Point` 和 `Pixels Per Unit`。**这个项目两样都不用。**

| Unity 里的操作 | Godot 里对应什么 | 本项目要不要做 |
|---|---|---|
| 每张图设 `Filter Mode = Point`（像素画必须） | 项目设置 → `渲染 → 纹理 → Canvas 纹理 → 默认纹理过滤 = Nearest` | ❌ **不用**（官方素材不是 16×16 复古像素画，开了反而锯齿） |
| 每张图设 `Pixels Per Unit = 16` | **没有这个概念**；图太大就改节点的 `Scale` | ✅ 到 [02 章](./02-玩家场景.md) 会做 |

> **一句话记住 Godot 和 Unity 在 2D 上的根本差异**：
> **Unity**：世界单位是抽象的，靠 **PPU** 把"图片像素"换算成"世界单位"。
> **Godot**：**世界坐标的单位就是像素**。一张 30×30 的图放上去就是 30×30 像素那么大，觉得大就调 `Scale`。
>
> 所以你**以后**如果用真正的复古像素素材（16×16 那种），再去把「默认纹理过滤」改成 `Nearest`——**那是一个全局开关，一次搞定，不用像 Unity 那样逐张图改**。

## 6. 项目文件组织（本项目不用建目录）

官方原话（翻译）：

> 在这个项目里，我们会做 **3 个独立的场景**：`Player`、`Mob` 和 `HUD`，然后把它们组合进游戏的 `Main` 场景。
> 在更大的项目里，建目录来放各类场景和脚本会有用；但**对这个相对小的游戏，你可以把场景和脚本都存在项目根目录**（`res://`）。

所以本项目最终会是"平铺"的：

```
DodgeTheCreeps/
├─ project.godot
├─ art/                  ← 素材（已就位）
├─ fonts/                ← 字体（已就位）
├─ player.tscn  mob.tscn  hud.tscn  main.tscn      ← 4 个场景
├─ player.gd    mob.gd    hud.gd    main.gd        ← 4 个脚本（GDScript 路线）
└─ （C# 路线还会多出）DodgeTheCreeps.csproj / .sln
```

> **对照 Unity**：Unity 里你会建 `Assets/Scripts/`、`Assets/Prefabs/`、`Assets/Scenes/`。
> Godot 里**小项目平铺是官方推荐做法**——因为 `.tscn` 文件里对脚本和素材的引用**存的是 UID/路径，不依赖目录层级**，所以你以后随时想整理成 `scenes/` + `scripts/` 也不会断引用。

### 6.1 C# 路线的额外文件

如果你选了 C#，**第一次给节点挂 C# 脚本时**（[02 章](./02-玩家场景.md) 或 [03 章](./03-玩家脚本.md)），Godot 会自动生成：

```
DodgeTheCreeps.csproj      ← 工程文件（自动生成，别手改）
DodgeTheCreeps.sln         ← 解决方案
.godot/mono/...            ← 中间产物
```

**这两个文件会自动出现在文件系统面板里**，看到是正常的。

## 7. 命名规范（先记住，因为后面要手打很多名字）

官方在教程开头就提醒了规范，因为**后面手动输入节点名、信号名、方法名的地方很多，而且拼错了不会当场报错**：

| | GDScript | C# |
|---|---|---|
| 类 / 节点名 | **`PascalCase`**：`Player`、`MobTimer` | 同左 |
| 变量 / 函数 | **`snake_case`**：`screen_size`、`show_message` | **`PascalCase`**：`ScreenSize`、`ShowMessage` |
| 私有字段 | `_underscore`：`_score` | **`_camelCase`**：`_score` |
| 常量 | `ALL_CAPS` | 同左 |

**本项目会出现的固定名字**（照着用，别自己改）：

| 场景 | 节点名 |
|---|---|
| `Player` | `AnimatedSprite2D`、`CollisionShape2D`、`Trail`（可选） |
| `Mob` | `AnimatedSprite2D`、`CollisionShape2D`、`VisibleOnScreenNotifier2D` |
| `Main` | `ColorRect`、`Player`、`MobTimer`、`ScoreTimer`、`StartTimer`、`StartPosition`、`MobPath`、`MobSpawnLocation`、`HUD`、`Music`、`DeathSound` |
| `HUD` | `ScoreLabel`、`MessageLabel`、`StartButton`、`MessageTimer` |

> **方法名两套语言不一样**：`_on_body_entered` ↔ `OnBodyEntered`、`show_message` ↔ `ShowMessage`、`_ready` ↔ `_Ready`。

## 8. C# 路线：现在做一次环境自检

| 检查 | 怎么做 | 期望 |
|---|---|---|
| Godot 是 .NET 版 | 你下载的文件名里带 **`mono`** | 是 |
| .NET SDK 装了 | PowerShell 跑 `dotnet --list-sdks` | 有版本输出（8.0+） |
| 知道「Build」按钮在哪 | 看编辑器**右上角** | 有一个 **「Build」**（或「生成」）按钮 |
| 有 C# 编辑器 | VS Code + C# 扩展 / Rider / VS | 有 |

> 🔴 **「Build」按钮是本篇 C# 路线最容易忘的一步**：**新增 `[Export]` 变量或新信号之后，不点它，Inspector 里就看不到**。官方教程专门为此画了警告图。

## 9. 本章的坑

| 现象 | 原因 |
|---|---|
| 文件系统面板里没有 `art` | 复制到了 `DodgeTheCreeps\art\art`（多套了一层）；检查目录层级 |
| 点图片看不到预览 | 导入还没完成，等几秒；或看「输出」面板报错 |
| 后面运行时画面被拉伸变形 | `Aspect` 没设成 `keep` |
| 后面 UI 或路径位置全对不上 | 视口不是 480×720 |
| 改了项目设置重新打开又变回去了 | 你改的是"编辑器设置"（Editor Settings）而不是"项目设置"（Project Settings）——两者是**两个不同的菜单** |
| 项目路径含中文导致导出失败 | 重建项目到纯英文路径 |
| C# 路线新建脚本时语言下拉里没有 `C#` | 你用的是**标准版** Godot，不是 .NET 版 |
