## 1. 新建 `Main` 场景

1. 菜单 **`场景 → 新建场景`**
2. `Ctrl+A` → 搜索 **`Node`**（**不是 `Node2D`！**）→ 创建
3. 改名成 **`Main`**

**为什么用 `Node` 而不是 `Node2D`**——官方原话（翻译）：

> 我们这里用 `Node` 而不是 `Node2D`，是因为**这个节点只是处理游戏逻辑的容器，它本身不需要 2D 功能**。

| 节点类型 | 什么时候用 |
|---|---|
| **`Node`** | 纯逻辑容器（本项目 `Main`） |
| `Node2D` | 需要坐标/旋转的 2D 对象（当"文件夹"用 `Node2D`） |
| `Control` | UI |

> **对照 Unity**：Unity 里"Create Empty"**永远**会带一个 `Transform`（也就是 3D 坐标）。Godot 把"要不要坐标"这件事**显式**化了——**这是更干净的设计**。

## 3. 加计时器、起点、刷怪路径

选中 `Main`，逐个 `Ctrl+A` 添加下面这些节点，**名字照抄**（脚本里要按名字找）：

| 节点名 | 类型 | 作用 |
|---|---|---|
| **`MobTimer`** | `Timer` | 每 0.5 秒生成一个敌人 |
| **`ScoreTimer`** | `Timer` | 每 1 秒分数 +1 |
| **`StartTimer`** | `Timer` | 开局先等 2 秒 |
| **`StartPosition`** | `Marker2D` | 玩家的起点位置 |
| **`MobPath`** | `Path2D` | 敌人生成位置的路径（屏幕边框） |
| **`MobSpawnLocation`** | `PathFollow2D` | **要作为 `MobPath` 的子节点** |

### 3.1 设置属性

| 节点 | 属性 | 值 |
|---|---|---|
| `MobTimer` | `等待时间 (Wait Time)` | **`0.5`** |
| `ScoreTimer` | `等待时间 (Wait Time)` | **`1`** |
| `StartTimer` | `等待时间 (Wait Time)` | **`2`** |
| `StartTimer` | **`单次 (One Shot)`** | **勾上** |
| `StartPosition` | `变换 → 位置 (Position)` | **`(240, 450)`** |

**`(240, 450)` 是什么位置**：视口是 `480 × 720` → `x = 240` 是**水平正中**，`y = 450` 是**偏下的位置**。**玩家从屏幕下方中央出发。**

> **`Marker2D` 是干什么的**：**一个只有位置、什么也不做**的节点。用来"**在编辑器里摆数据**"，不用把坐标写死在代码里（[§6](#6-逐段讲解) 会看到 `$Player.start($StartPosition.position)`）。
> **对照 Unity**：Unity 里你会用空 GameObject 做同样的事。Godot 的 `Marker2D` 更明确。
>
> **`Timer` 节点 vs `await`**：`Timer` 是**放在场景里的计时器**，到点发 `timeout` 信号——适合**周期性**的事（每 0.5 秒刷怪）。要"就地等一会儿"的话用 `await get_tree().create_timer(1.0).timeout`（[06 章](./06-HUD.md) 会用到）。

### 3.2 ✅ 检查点

「场景」面板现在长这样：

```
Main (Node)
├─ Player            ← 实例化进来的
├─ MobTimer (Timer)
├─ ScoreTimer (Timer)
├─ StartTimer (Timer)
├─ StartPosition (Marker2D)
└─ MobPath (Path2D)
   └─ MobSpawnLocation (PathFollow2D)     ← 确认它是 MobPath 的子节点
```

## 4. 画 `MobPath`（敌人的生成位置）

这一步要**在 2D 视图里画一条贴着屏幕四边的矩形路径**。

### 4.1 选中 `MobPath`

选中后，**主视区上方会多出一排路径编辑按钮**（在"选择/旋转/缩放"那几个工具按钮旁边）。

### 4.2 打开吸附（很重要，否则点不准）

在工具栏上确认这两个开着：

| 按钮 | 作用 |
|---|---|
| **使用网格吸附 (Use Grid Snap)** | 让点吸附到网格（默认网格 8×8） |
| **使用智能吸附 (Use Smart Snap)** | 吸附到其他对象/参考线 |

### 4.3 点出四个角

1. 点工具栏上的 **「添加点 (Add Point)」** 按钮（三个按钮里中间那个）
2. 在 2D 视图里**依次点这 4 个位置**（对应屏幕四角）：

| 顺序 | 坐标 | 位置 |
|---|---|---|
| 1 | **(0, 0)** | 左上角 |
| 2 | **(480, 0)** | 右上角 |
| 3 | **(480, 720)** | 右下角 |
| 4 | **(0, 720)** | 左下角 |
| 5 | **(0, 0)** | **再点回左上角**（闭合路径） |

3. 点完按 **`Esc`** 或点「选择」按钮退出添加模式

> 🔴 **最后一个点必须回到起点**，否则路径不闭合，`progress_ratio` 的取值范围会不对。

### 4.4 如果点不准：用检查器精确输入

点不准时，选中 `MobPath` → 检查器 → 展开 **`曲线 (Curve)`** → `点 (Points)` 数组：

- 数组里应该有 **5 个点**
- 逐个展开，把 `位置 (Position)` 改成上面的 5 组坐标
- **`进 (In)` / `出 (Out)` 控制柄全部保持 `(0, 0)`**（直线段，不要曲线）

**官方成品里这条曲线的数据**（可以对照）：

```
点1: (0, 0)     点2: (480, 0)    点3: (480, 720)
点4: (0, 720)   点5: (0, 0)      全部 In/Out = (0,0)
```

### 4.5 `MobSpawnLocation` 的位置

`MobSpawnLocation` 是 `PathFollow2D` 类型——**它的位置由 `progress_ratio`（0~1 的百分比）自动算出来**，你不用手动摆。

**检查一下**：检查器里 `进度比 (Progress Ratio)` 默认是 `0`，所以它会落在路径起点 `(0,0)`。

### 4.6 ✅ 检查点

- 2D 视图里能看到一条**贴着屏幕四边的红色/橙色矩形线**
- `MobPath` 的 `Curve` 里有正好 **5 个点**
- `MobSpawnLocation` 在 `MobPath` 下面（作为子节点）

> **为什么用 `Path2D` + `PathFollow2D`**：这是 Godot 的常用组合——做巡逻路线、轨道、生成点分布都靠它。**它把一个"沿路径取任意一点"的能力做成了一对节点**。
> **对照 Unity**：Unity 里没有内建等价物，通常要装插件或自己算样条。

## 6. 代码

### 6.1 GDScript —— `main.gd`

```gdscript
extends Node

@export var mob_scene: PackedScene
var score

func game_over():
	$ScoreTimer.stop()
	$MobTimer.stop()
	$HUD.show_game_over()
	$Music.stop()
	$DeathSound.play()

func new_game():
	get_tree().call_group(&"mobs", &"queue_free")
	score = 0
	$Player.start($StartPosition.position)
	$StartTimer.start()
	$HUD.update_score(score)
	$HUD.show_message("Get Ready")
	$Music.play()

func _on_MobTimer_timeout():
	# Create a new instance of the Mob scene.
	var mob = mob_scene.instantiate()

	# Choose a random location on Path2D.
	var mob_spawn_location = get_node(^"MobPath/MobSpawnLocation")
	mob_spawn_location.progress_ratio = randf()

	# Set the mob's position to a random location.
	mob.position = mob_spawn_location.position

	# Set the mob's direction perpendicular to the path direction.
	var direction = mob_spawn_location.rotation + PI / 2

	# Add some randomness to the direction.
	direction += randf_range(-PI / 4, PI / 4)
	mob.rotation = direction

	# Choose the velocity for the mob.
	var velocity = Vector2(randf_range(150.0, 250.0), 0.0)
	mob.linear_velocity = velocity.rotated(direction)

	# Spawn the mob by adding it to the Main scene.
	add_child(mob)

func _on_ScoreTimer_timeout():
	score += 1
	$HUD.update_score(score)

func _on_StartTimer_timeout():
	$MobTimer.start()
	$ScoreTimer.start()
```

### 6.2 C# —— `Main.cs`

```csharp
using Godot;

public partial class Main : Node
{
#pragma warning disable 649
    // We assign this in the editor, so we don't need the warning about not being assigned.
    [Export]
    public PackedScene MobScene { get; set; }
#pragma warning restore 649

    private int _score;

    public void GameOver()
    {
        GetNode<Timer>("MobTimer").Stop();
        GetNode<Timer>("ScoreTimer").Stop();

        GetNode<HUD>("HUD").ShowGameOver();

        GetNode<AudioStreamPlayer>("Music").Stop();
        GetNode<AudioStreamPlayer>("DeathSound").Play();
    }

    public void NewGame()
    {
        // Note that for calling Godot-provided methods with strings,
        // we have to use the original Godot snake_case name.
        GetTree().CallGroup("mobs", Node.MethodName.QueueFree);
        _score = 0;

        var player = GetNode<Player>("Player");
        var startPosition = GetNode<Marker2D>("StartPosition");
        player.Start(startPosition.Position);

        GetNode<Timer>("StartTimer").Start();

        var hud = GetNode<HUD>("HUD");
        hud.UpdateScore(_score);
        hud.ShowMessage("Get Ready!");

        GetNode<AudioStreamPlayer>("Music").Play();
    }

    private void OnStartTimerTimeout()
    {
        GetNode<Timer>("MobTimer").Start();
        GetNode<Timer>("ScoreTimer").Start();
    }

    private void OnScoreTimerTimeout()
    {
        _score++;

        GetNode<HUD>("HUD").UpdateScore(_score);
    }

    // We also specified this function name in PascalCase in the editor's connection window.
    private void OnMobTimerTimeout()
    {
        // Note: Normally it is best to use explicit types rather than the `var`
        // keyword. However, var is acceptable to use here because the types are
        // obviously Mob and PathFollow2D, since they appear later on the line.

        if (MobScene is null)
        {
            GD.PrintErr("Mob scene is not set. You need to set it in the inspector.");
            return;
        }
        // Create a new instance of the Mob scene.
        Mob mob = MobScene.Instantiate<Mob>();

        // Choose a random location on Path2D.
        var mobSpawnLocation = GetNode<PathFollow2D>("MobPath/MobSpawnLocation");
        mobSpawnLocation.ProgressRatio = GD.Randf();

        // Set the mob's direction perpendicular to the path direction.
        float direction = mobSpawnLocation.Rotation + Mathf.Pi / 2;

        // Set the mob's position to a random location.
        mob.Position = mobSpawnLocation.Position;

        // Add some randomness to the direction.
        direction += (float)GD.RandRange(-Mathf.Pi / 4, Mathf.Pi / 4);
        mob.Rotation = direction;

        // Choose the velocity for the mob.
        var velocity = new Vector2((float)GD.RandRange(150.0, 250.0), 0);
        mob.LinearVelocity = velocity.Rotated(direction);

        // Spawn the mob by adding it to the Main scene.
        AddChild(mob);
    }
}
```

## 7. 连信号（**本章的核心动作**）

**先说明**：`Main` 里的 `game_over` / `new_game` 会被**别的节点触发**——这个"触发关系"就是**信号连接**。
**所有"谁和谁说话"的关系，都集中在 `Main` 这一个地方**，一眼能看清整个游戏的骨架。

### 7.1 现在能连的 4 条

| # | 从 | 信号 | 到 | 接收方法（GDScript / C#） |
|---|---|---|---|---|
| 1 | `MobTimer` | `timeout` | `Main` | `_on_MobTimer_timeout` / `OnMobTimerTimeout` |
| 2 | `ScoreTimer` | `timeout` | `Main` | `_on_ScoreTimer_timeout` / `OnScoreTimerTimeout` |
| 3 | `StartTimer` | `timeout` | `Main` | `_on_StartTimer_timeout` / `OnStartTimerTimeout` |
| 4 | `Player` | **`hit`**（自定义） | `Main` | **`game_over` / `GameOver`** |

**操作**（对每一条重复）：

1. 选中**发出信号**的节点（`MobTimer` / `ScoreTimer` / `StartTimer` / `Player`）
2. 右侧 → **「节点」** 面板 → **「信号」** 标签
3. 找到对应信号 → **双击**
4. 对话框里：
   - **连接到节点** → 选 **`Main`**
   - **接收方法** → 填上表里的名字（GDScript 一般会自动生成并预填）
5. 点「连接」

> ⚠️ **第 4 条要注意**：`Player` 的 `hit` 是我们在 [03 章](./03-玩家脚本.md) 自己声明的**自定义信号**。
> **如果信号列表里看不到 `hit`**：
> - **C# 路线**：99% 是**忘了点「Build」**——Build 之后新信号才会出现在编辑器里。
> - GDScript 路线：确认 `player.gd` 里有 `signal hit` 这一行，并且 `player.tscn` 已保存。

### 7.2 还有 1 条要等 06 章

| 从 | 信号 | 到 | 接收方法 |
|---|---|---|---|
| `HUD` | `start_game` | `Main` | `new_game` / `NewGame` |

**这条等 [06 章](./06-HUD.md) 把 `HUD` 实例化进来之后再连。**

### 7.3 ✅ 检查点

保存 `main.tscn` 后，打开文件能看到 **4 条** `[connection ...]`：

```
[connection signal="hit" from="Player" to="." method="game_over"]
[connection signal="timeout" from="MobTimer" to="." method="_on_MobTimer_timeout"]
[connection signal="timeout" from="ScoreTimer" to="." method="_on_ScoreTimer_timeout"]
[connection signal="timeout" from="StartTimer" to="." method="_on_StartTimer_timeout"]
```

> **`to="."`** 里的 `.` 表示**根节点自己（`Main`）**。

## 9. 逐段讲解

### 9.1 `new_game()`：一局开始

```gdscript
func new_game():
	get_tree().call_group(&"mobs", &"queue_free")   # ① 清场
	score = 0
	$Player.start($StartPosition.position)          # ② 玩家就位并显示
	$StartTimer.start()                             # ③ 开始 2 秒倒计时
	$HUD.update_score(score)
	$HUD.show_message("Get Ready")
	$Music.play()
```

| # | 干什么 | 关键点 |
|---|---|---|
| ① | **把场上所有敌人清掉** | `call_group("mobs", "queue_free")` = "**给所有在 `mobs` 分组的节点发 `queue_free`**" |
| ② | 玩家移到起点、显示出来、打开碰撞 | 对应 [03 章 §5.7](./03-玩家脚本.md#57-start把玩家放出来) 的 `start()` |
| ③ | 启动 `StartTimer` | 2 秒后才真正开始刷怪（给玩家看"Get Ready!"的时间） |

**① 是本节最值得学的一行**：

```gdscript
get_tree().call_group(&"mobs", &"queue_free")
```

- **不需要维护 `List<Mob>`**、不需要遍历、不需要知道有几个敌人；
- 靠的是 [04 章 §6](./04-敌人.md#6-把-mob-加进分组-mobs别忘) 给 `Mob` 加的那个 **`mobs` 分组**。

**C# 版要注意方法名**——官方专门加了注释：

```csharp
        // Note that for calling Godot-provided methods with strings,
        // we have to use the original Godot snake_case name.
        GetTree().CallGroup("mobs", Node.MethodName.QueueFree);
```

> **对照 Unity**：Unity 里你要么维护一个 `List<Enemy>`，要么 `FindObjectsOfType<Enemy>()`（全场景扫描，慢）。**Godot 的分组是内建的索引，一行广播。**

### 9.2 刷怪的 7 步

```gdscript
	var mob = mob_scene.instantiate()                        # ① 造一个敌人（还没进场景）
	var mob_spawn_location = get_node(^"MobPath/MobSpawnLocation")
	mob_spawn_location.progress_ratio = randf()              # ② 在路径上随机取一点
	mob.position = mob_spawn_location.position               # ③ 敌人放到那个位置
	var direction = mob_spawn_location.rotation + PI / 2      # ④ 方向 = 路径切线 + 90°
	direction += randf_range(-PI / 4, PI / 4)                # ⑤ 加随机偏移
	mob.rotation = direction
	var velocity = Vector2(randf_range(150.0, 250.0), 0.0)   # ⑥ 定速度（150~250）
	mob.linear_velocity = velocity.rotated(direction)
	add_child(mob)                                           # ⑦ 挂进场景！
```

| 步骤 | 详解 |
|---|---|
| ② `progress_ratio = randf()` | `0.0 ~ 1.0` 表示"**沿路径的百分比位置**"。设成随机值 = **在整条屏幕边框上随机取一点**（`randf()` 返回 `[0,1)`） |
| ④ `+ PI / 2` | `PathFollow2D` 的 `rotation` 是**路径的切线方向**（沿着边走的方向）。加 90° 得到**垂直方向** → 敌人**朝屏幕内部飞**（而不是沿着边框绕圈） |
| ⑤ `± PI/4` | 加 ±45° 随机偏移；否则所有敌人都朝正中心飞，太机械 |
| ⑥ `velocity.rotated(direction)` | 把"**向右的向量**"旋转到目标方向——这是"给一个角度 + 一个速度，得到速度向量"的标准写法 |
| ⑦ `add_child(mob)` | 🔴 **忘了这行，敌人就"造了但不存在"**（[00 章 §2](./00-核心概念地图.md#2-scene既是关卡也是prefab)） |

**注意顺序**：`mob.position` / `mob.rotation` / `linear_velocity` 都是在 `add_child` **之前**设好的。

> **这是个好习惯**：Godot 允许你在"游离状态"下把对象配置完整，**再一次性挂进树**——避免"半初始化状态"被 `_process` 或物理引擎看到。
> **Unity 做不到**：`Instantiate` 出来的对象**已经**在场景里了，第一帧就可能跑逻辑。

**为什么是 `linear_velocity` 而不是自己更新位置**：`Mob` 是 `RigidBody2D`，**给它一个速度，物理引擎就会自己把它推着走**。所以 `mob.gd` 里一行移动代码都不需要（[04 章 §9](./04-敌人.md#9-运行验证)）。

### 9.3 `game_over()`：一局结束

```gdscript
func game_over():
	$ScoreTimer.stop()
	$MobTimer.stop()
	$HUD.show_game_over()
	$Music.stop()
	$DeathSound.play()
```

- **先停计时器**：不然玩家死了还在刷怪、还在加分；
- **不销毁任何东西、不切换场景**——只是停表 + 让 HUD 显示"Game Over"。下次点 Start 时 `new_game()` 会清场重来；
- **游戏状态全部由 `Main` 一个节点持有**（`score` 是它的私有变量），所以"重开"只需要重置它自己。

> **对照 Unity**：你之前那个教程里"重开一局"是 `SceneManager.LoadScene(buildIndex)` **重载整个场景**。
> **Godot 这里根本不用重载场景**——一局的内容（敌人）是动态生成的，**清场就够了**。这是更轻的做法。

### 9.4 三个 `Timer` 的联动

```gdscript
func _on_StartTimer_timeout():
	$MobTimer.start()
	$ScoreTimer.start()
```

**`StartTimer` 是"发令枪"**：它自己只跑一次（`One Shot`），到点后**启动另外两个计时器**。

在编辑器里看，这是一条**清晰的信号链**：

```
点 Start 按钮
   → HUD.start_game
      → Main.new_game()          ← 重置分数、放出玩家、启动 StartTimer
         → 2 秒后 StartTimer.timeout
            → Main._on_StartTimer_timeout()
               → 启动 MobTimer 和 ScoreTimer
                  → 每 0.5 秒刷怪 / 每秒加分
```

## 10. 和 Unity 的对照小结

| 概念 | Unity | Godot |
|---|---|---|
| 逻辑容器根节点 | 空 GameObject（自带 Transform） | **`Node`**（没有坐标） |
| 引用模板 | `public GameObject prefab` + 拖 | **`@export var scene: PackedScene`** + 拖 |
| 造实例 | `Instantiate(prefab)` | `scene.instantiate()` |
| 放进场景 | 自动（已经在场景里） | **必须 `add_child()`** |
| 摆标记点 | 空 GameObject | `Marker2D` |
| 沿路径生成 | 自己算样条 / 装插件 | **`Path2D` + `PathFollow2D`** |
| 定时器 | `Invoke` / 协程 / 在 `Update` 里计时 | **`Timer` 节点 + `timeout` 信号** |
| 批量清场 | `List` 遍历 / `FindObjectsOfType` | **`call_group("mobs", "queue_free")`** |
| 事件连接 | 代码里直调 / `UnityEvent` | **编辑器连线 / `.connect()`** |
