## 3. 写代码

打开 `player.gd`（或 `Player.cs`），**把内容整体替换**成下面的完整代码。

> 代码来自**官方成品项目**（[MIT 授权](https://github.com/godotengine/godot-demo-projects/blob/master/LICENSE.md)），注释是官方原文。

### 3.1 GDScript —— `player.gd`

```gdscript
extends Area2D

signal hit

@export var speed = 400 # How fast the player will move (pixels/sec).
var screen_size # Size of the game window.

func _ready():
	screen_size = get_viewport_rect().size
	hide()

func _process(delta):
	var velocity = Vector2.ZERO # The player's movement vector.
	if Input.is_action_pressed(&"move_right"):
		velocity.x += 1
	if Input.is_action_pressed(&"move_left"):
		velocity.x -= 1
	if Input.is_action_pressed(&"move_down"):
		velocity.y += 1
	if Input.is_action_pressed(&"move_up"):
		velocity.y -= 1

	if velocity.length() > 0:
		velocity = velocity.normalized() * speed
		$AnimatedSprite2D.play()
	else:
		$AnimatedSprite2D.stop()

	position += velocity * delta
	position = position.clamp(Vector2.ZERO, screen_size)

	if velocity.x != 0:
		$AnimatedSprite2D.animation = &"right"
		$AnimatedSprite2D.flip_v = false
		$Trail.rotation = 0
		$AnimatedSprite2D.flip_h = velocity.x < 0
	elif velocity.y != 0:
		$AnimatedSprite2D.animation = &"up"
		rotation = PI if velocity.y > 0 else 0

func start(pos):
	position = pos
	rotation = 0
	show()
	$CollisionShape2D.disabled = false

func _on_body_entered(_body):
	hide() # Player disappears after being hit.
	hit.emit()
	# Must be deferred as we can't change physics properties on a physics callback.
	$CollisionShape2D.set_deferred(&"disabled", true)
```

> 🔴 **如果你在 [02 章 §6](./02-玩家场景.md#6-可选但推荐拖尾粒子-trail) 没有做 `Trail` 节点**，请**删掉这一行**：
> ```gdscript
> 		$Trail.rotation = 0
> ```
> 不删的话运行时会报 `Node not found: Trail`。

### 3.2 C# —— `Player.cs`

```csharp
using Godot;

public partial class Player : Area2D
{
    [Signal]
    public delegate void HitEventHandler();

    [Export]
    public int Speed { get; set; } = 400; // How fast the player will move (pixels/sec).

    public Vector2 ScreenSize { get; set; } // Size of the game window.

    public override void _Ready()
    {
        ScreenSize = GetViewportRect().Size;
        Hide();
    }

    public override void _Process(double delta)
    {
        var velocity = Vector2.Zero;

        if (Input.IsActionPressed("move_right"))
        {
            velocity.X += 1;
        }

        if (Input.IsActionPressed("move_left"))
        {
            velocity.X -= 1;
        }

        if (Input.IsActionPressed("move_down"))
        {
            velocity.Y += 1;
        }

        if (Input.IsActionPressed("move_up"))
        {
            velocity.Y -= 1;
        }

        var animatedSprite = GetNode<AnimatedSprite2D>("AnimatedSprite2D");

        if (velocity.Length() > 0)
        {
            velocity = velocity.Normalized() * Speed;
            animatedSprite.Play();
        }
        else
        {
            animatedSprite.Stop();
        }

        Position += velocity * (float)delta;
        Position = new Vector2(
            x: Mathf.Clamp(Position.X, 0, ScreenSize.X),
            y: Mathf.Clamp(Position.Y, 0, ScreenSize.Y)
        );

        if (velocity.X != 0)
        {
            animatedSprite.Animation = "right";
            animatedSprite.FlipV = false;
            animatedSprite.FlipH = velocity.X < 0;
        }
        else if (velocity.Y != 0)
        {
            animatedSprite.Animation = "up";
            animatedSprite.FlipV = velocity.Y > 0;
        }
    }

    public void Start(Vector2 position)
    {
        Position = position;
        Show();
        GetNode<CollisionShape2D>("CollisionShape2D").Disabled = false;
    }

    public void OnBodyEntered(PhysicsBody2D body)
    {
        Hide(); // Player disappears after being hit.
        EmitSignal(SignalName.Hit);
        // Must be deferred as we can't change physics properties on a physics callback.
        GetNode<CollisionShape2D>("CollisionShape2D").SetDeferred(CollisionShape2D.PropertyName.Disabled, true);
    }
}
```

> 💡 C# 版**没有** `$Trail` 那行（成品 C# 版没引用 `Trail`），也没有 `rotation = PI`——它用 **`FlipV`（垂直翻转精灵）** 表达"朝下"。这是**两套官方代码的真实实现差异**（见 [§5.6](#56-动画切换--精灵翻转本节最巧的一段)）。

## 5. 逐段讲解（每段都对应一个"为什么"）

### 5.1 `@export`：把变量搬进 Inspector

```gdscript
@export var speed = 400 # How fast the player will move (pixels/sec).
```

```csharp
[Export]
public int Speed { get; set; } = 400; // How fast the player will move (pixels/sec).
```

官方原话（翻译）：

> 在 `speed` 上用 `export` 关键字，可以让我们在 **Inspector 里设置它的值**。**如果你在 Inspector 里改了值，它会覆盖脚本里的默认值（脚本本身不会被修改）。**

| 语言 | 写法 | 注意 |
|---|---|---|
| GDScript | `@export var speed = 400` | 类型自动推断 |
| C# | `[Export] public int Speed { get; set; } = 400;` | **只能标属性**；**必须 Build 后才出现在 Inspector** |

### 5.2 `_ready()`：拿窗口尺寸 + 先把自己藏起来

```gdscript
func _ready():
	screen_size = get_viewport_rect().size
	hide()
```

| 这行 | 干什么 | Unity 对应 |
|---|---|---|
| `screen_size = get_viewport_rect().size` | 拿视口尺寸 → `(480, 720)`，**作为移动边界** | `Camera.main.ScreenToWorldPoint` 那一套 |
| `hide()` | 一开始**隐藏玩家** | `SetActive(false)` |

**为什么要隐藏**：游戏不是一启动就开始的——要先显示标题和"Get Ready"，等 [05 章](./05-主场景.md) 的 `StartTimer` 走完，由 `Main` 调 `start()` 才让玩家现身。

> ⚠️ 这就是**为什么 `F6` 之后屏幕上什么都没有**的原因（[02 章 §8](./02-玩家场景.md#8-保存--单独运行测试) 说过的"正常现象"）。

### 5.3 `_process(delta)`：这就是主循环

```gdscript
func _process(delta):
	var velocity = Vector2.ZERO # The player's movement vector.
	if Input.is_action_pressed(&"move_right"):
		velocity.x += 1
	...
```

官方解释（翻译）：

> `_process()` **每帧都会被调用**，所以用它来更新那些"会频繁变化"的东西。
> 我们先把 `velocity` 设为 `(0, 0)`——默认玩家不动。然后检查每个输入，对 `velocity` 做加减，得到总方向。
> 例如同时按住 `right` 和 `down`，`velocity` 会是 `(1, 1)`。**这种情况玩家斜着走会比横着走更快。**

**怎么解决？归一化：**

```gdscript
	if velocity.length() > 0:
		velocity = velocity.normalized() * speed
```

官方原话（翻译）：

> 我们可以通过**归一化（normalize）**来防止这一点——归一化会把向量的**长度设成 1**，然后乘以想要的速度。**这样就再也不会斜着变快了。**

| | 横着走 | 斜着走 |
|---|---|---|
| 未归一化 | 长度 1 → 速度 400 | 长度 **1.414** → 速度 **565** ❌ |
| 归一化后 | 长度 1 → 速度 400 | 长度 1 → 速度 400 ✅ |

> **同一个坑，同一个解法**：Unity 里也是 `velocity.normalized`。

### 5.4 动画的播放与停止

```gdscript
		$AnimatedSprite2D.play()
	else:
		$AnimatedSprite2D.stop()
```

**有速度就播、没速度就停**——两行搞定。

> **对照 Unity**：那边要建 `Idle`/`Walk` 状态、配 Transition、写 `SetFloat("speed", v)`。**Godot 直接 `play()` / `stop()`**。

### 5.5 移动 + 边界限制

```gdscript
	position += velocity * delta
	position = position.clamp(Vector2.ZERO, screen_size)
```

| 写法 | 含义 |
|---|---|
| `velocity * delta` | `velocity` 是"**每秒**多少像素"，乘 `delta`（上一帧耗时**秒数**）才是"**这一帧**该走多少" |
| `position += ...` | 直接改位置（`Area2D` 不受物理推动，位置完全由我们说了算） |
| `.clamp(Vector2.ZERO, screen_size)` | 把坐标限制在 `(0,0) ~ (480,720)` 的矩形内 → **玩家跑不出屏幕** |

**C# 没有向量版 `clamp`**，所以官方逐轴写：

```csharp
        Position = new Vector2(
            x: Mathf.Clamp(Position.X, 0, ScreenSize.X),
            y: Mathf.Clamp(Position.Y, 0, ScreenSize.Y)
        );
```

> **`delta` 是什么**：上一帧到这一帧经过了多少**秒**（60 FPS 时约 `0.0167`）。
> **为什么必须乘**：不乘的话 `position += velocity` 就变成"**每帧加 400 像素**"——**帧率越高跑得越快**。这是游戏开发的通用常识。
> **Unity 对应**：`Time.deltaTime` 是同一个东西，只是 Godot 把它**当参数传给你**，而不是藏在全局单例里。

### 5.6 动画切换 + 精灵翻转（**本节最巧的一段**）

素材只有"**向右走**"和"**向上走**"两套，四个方向靠**翻转/旋转**表示：

| 往哪走 | 做法 |
|---|---|
| 右 | 动画 `right`，不翻转 |
| 左 | 动画 `right`，**水平翻转**（`flip_h = true`） |
| 上 | 动画 `up`，节点旋转 0° |
| 下 | 动画 `up`，**节点旋转 180°**（`rotation = PI`） |

```gdscript
	if velocity.x != 0:
		$AnimatedSprite2D.animation = &"right"
		$AnimatedSprite2D.flip_v = false
		$Trail.rotation = 0
		$AnimatedSprite2D.flip_h = velocity.x < 0
	elif velocity.y != 0:
		$AnimatedSprite2D.animation = &"up"
		rotation = PI if velocity.y > 0 else 0
```

三个细节：

1. **`velocity.x != 0` 优先于 `velocity.y`**：斜着走时**按水平方向显示**（因为是 `if / elif`）。
2. **`flip_v = false` 和 `$Trail.rotation = 0` 是"状态复位"**——从竖直切回水平时，必须清掉上一轮留下的翻转/旋转。**不做复位就会出现"往左走但角色上下颠倒"的鬼畜现象。**
3. **`rotation = PI if velocity.y > 0 else 0`** 是 GDScript 的三元表达式（`(值) if 条件 else (值)`）。

**而 C# 版是这样**：

```csharp
        else if (velocity.Y != 0)
        {
            animatedSprite.Animation = "up";
            animatedSprite.FlipV = velocity.Y > 0;      // ← 翻转精灵，而不是转节点
        }
```

**同一个需求，两种做法**：

| | GDScript 版：`rotation = PI` | C# 版：`FlipV = true` |
|---|---|---|
| 转的是什么 | **整个节点** | **只翻精灵的贴图** |
| 拖尾粒子 | 跟着转（更自然） | 不转 |
| 碰撞形状 | **跟着转**（竖直胶囊转成横的） | 不受影响 |
| 影响面 | 大 | 小、局部 |

> 💡 **这是本节最值得品味的地方**：两套官方代码**并不逐行等价**。照搬的时候要**盯着成品代码**，不能只看教程正文。
> 自己写的时候想清楚：**转节点 = 整个物体转向，翻精灵 = 只换贴图朝向。**

### 5.7 `start()`：把玩家"放出来"

```gdscript
func start(pos):
	position = pos
	rotation = 0
	show()
	$CollisionShape2D.disabled = false
```

| 行 | 为什么需要 |
|---|---|
| `position = pos` | 挪到起点（`Main` 会传 `StartPosition` 的位置） |
| `rotation = 0` | **复位**（上一局可能死在"朝下"的状态） |
| `show()` | 和 `_ready()` 里的 `hide()` 配对 |
| `CollisionShape2D.disabled = false` | **重新打开碰撞**——因为被撞时我们把它关掉了 |

**这个函数由 [05 章](./05-主场景.md) 的 `Main.new_game()` 调用。**

### 5.8 被撞：`_on_body_entered` + 自定义信号

```gdscript
func _on_body_entered(_body):
	hide() # Player disappears after being hit.
	hit.emit()
	# Must be deferred as we can't change physics properties on a physics callback.
	$CollisionShape2D.set_deferred(&"disabled", true)
```

| 行 | 作用 |
|---|---|
| `hide()` | 玩家消失（**不是销毁**！后面还能 `start()` 复用） |
| `hit.emit()` | **广播"我被撞了"** → [05 章](./05-主场景.md) 的 `Main.game_over()` 会接住 |
| `set_deferred("disabled", true)` | 关掉碰撞，防止**同一帧内重复触发** |

**为什么必须 `set_deferred`**——官方注释写得很明确（翻译）：

> **必须延迟**，因为我们**不能在物理回调里修改物理属性**。

| 写法 | 结果 |
|---|---|
| `$CollisionShape2D.disabled = true` | ❌ 报错（在物理回调里改物理属性） |
| `$CollisionShape2D.set_deferred(&"disabled", true)` | ✅ 延迟到本次物理计算结束后执行 |

> 这是 Godot 的一条**硬规则**，和 Unity 里"`Destroy` 延迟到帧末"是同类知识。**违反了往往报错很隐晦**，记住它。

**参数为什么叫 `_body`**：GDScript 约定——**不打算用的参数用下划线开头**，避免"未使用参数"的警告。

### 5.9 自定义信号 `signal hit`

```gdscript
signal hit
...
hit.emit()
```

```csharp
[Signal]
public delegate void HitEventHandler();
...
EmitSignal(SignalName.Hit);
```

| | GDScript | C# |
|---|---|---|
| 声明 | `signal hit` | `[Signal] public delegate void HitEventHandler();` |
| 命名 | 小写 | **必须以 `EventHandler` 结尾**，否则引擎不认 |
| 发出 | `hit.emit()` | `EmitSignal(SignalName.Hit)` —— **用生成的常量，别手写字符串** |

**这个信号是"玩家"和"游戏流程"之间唯一的连接**：玩家只管喊"我被撞了"，至于"撞了要结束游戏"是 [05 章](./05-主场景.md) `Main` 的事。

> **这就是信号的价值**：`player.gd` **完全不知道 `Main` 存在**，也不知道什么叫"游戏结束"。
> **对照 Unity**：Unity 里常见做法是 `Player` 里直接 `GameManager.instance.GameOver()`——**发送方必须知道接收方**，耦合在代码里。

## 7. 和 Unity 的对照小结

| 概念 | Unity | Godot |
|---|---|---|
| 输入动作 | 内置 `Horizontal`/`Vertical`（旧 Input Manager） | **Input Map 自定义**，可多绑键/手柄 |
| 读输入 | `Input.GetAxisRaw("Horizontal")` | `Input.is_action_pressed("move_right")` |
| 帧间隔 | `Time.deltaTime`（全局） | **`_process(delta)` 的参数** |
| 移动 | `transform.position += v * Time.deltaTime` | `position += velocity * delta` |
| 边界限制 | 自己 `Mathf.Clamp` | `Vector2.clamp(...)`（GDScript 有向量版） |
| 精灵翻转 | `SpriteRenderer.flipX = true` | `AnimatedSprite2D.flip_h = true` |
| 播动画 | `Animator.SetTrigger` + 配状态机 | **`play()` / `stop()` / `animation = "名字"`** |
| 检测被撞 | `OnTriggerEnter2D`（要求一方有刚体） | **`body_entered` 信号**（`Area2D` 自己就能检测） |
| 广播事件 | 单例直调 / `UnityEvent` | **`signal` + `emit()`** |
| 隐藏对象 | `SetActive(false)` | **`hide()`** |
| 关碰撞 | `collider.enabled = false` | `CollisionShape2D.disabled = true`（**物理回调里要用 `set_deferred`**） |

## 8. 本章的坑

| 现象 | 原因 |
|---|---|
| 按方向键完全不动 | ① Input Map 里动作名不是 `move_right` 等（**大小写敏感**）② 脚本没挂在 `Player` 上 |
| 斜着走比直着走快 | 忘了 `velocity.normalized()` |
| 速度取决于帧率 / 一卡一卡 | `velocity * delta` 里漏了 `delta` |
| 往左走后再往上走，小人上下颠倒 | **状态复位漏了**（`flip_v = false` / `rotation = 0` 那段） |
| 报 `Node not found: Trail` | 没做 `Trail` 节点，却保留了 `$Trail.rotation = 0` → **删掉那行** |
| 报 `Node not found: AnimatedSprite2D` | 子节点名字和 `$AnimatedSprite2D` 不一致（大小写/拼写） |
| 报错"不能在物理回调里修改物理属性" | 用了 `$CollisionShape2D.disabled = true`，必须 `set_deferred` |
| **`F6` 后屏幕上什么都没有**（连小人都没有） | `_ready()` 里的 `hide()` / `Hide();` 起作用了 → 见 [§6](#6-运行验证这次真的能动了) 第一步：临时注释掉它再 `F6` |
| 小人一出现就卡在**左上角**（半张脸） | `_ready()` 里的 `hide()` 漏了；现在的"出现"是由 `start()` 控制的（[05 章](./05-主场景.md)） |
| **C# 里 Inspector 看不到 `Speed`** | **忘了点「Build」** |
| C# 运行报 `OnBodyEntered` 不存在 | 连信号时方法名拼写/大小写不对（编辑器不校验） |
| 角色动但**动画不播** | **动画名不一致**（`right` vs `walk`）——脚本里写什么，SpriteFrames 里就得叫什么 |
| 反复被撞、`game_over` 触发多次 | `set_deferred` 那行漏了（碰撞没及时关掉） |
