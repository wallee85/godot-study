# 04 · 玩家与敌人：移动、碰撞与回合制

> 本章是全教程最硬的一章。你会一次碰到：**脚本继承、事件驱动输入、射线探测、Area2D 拾取、Tween、await、回合制状态机**。
> **建议分 3 次做完**：先 `MovingObject`，再 `Player`，最后 `Enemy`。

## 1. 先看类图，别急着写

```
CharacterBody2D（Godot 的"实体"节点）
      ▲
      │ 继承
MovingObject            (基类，自己不挂在任何物体上)
 ├─ move_time
 ├─ try_move()           ← 射线探测 → 能走就补间滑过去
 ├─ _slide_to()          ← Tween：一格走 move_time 秒
 ├─ on_blocked()         ← virtual：子类覆写"被挡住时干什么"
 └─ _probe()             ← intersect_ray 查询

      ┌───────────┴───────────┐
   Player                  Enemy
(读输入、吃道具、算分)   (追玩家、攻击、隔回合行动)

Wall : StaticBody2D       ← 独立，不继承 MovingObject（它不会动）
Pickup : Area2D           ← 食物/苏打（纯数据）
```

## 2. 核心概念①：脚本继承，以及 `super()` 陷阱

**Godot 里继承和 C# 一样直白**：

```gdscript
# GDScript：基类
class_name MovingObject
extends CharacterBody2D
```

```gdscript
# GDScript：子类
class_name Player
extends MovingObject
```

```csharp
// C#：一模一样
public abstract partial class MovingObject : CharacterBody2D { }
public partial class Player : MovingObject { }
```

三个差异点：

```gdscript
# 基类
func _ready() -> void:
	_cache_nodes()          # 缓存子节点引用

# 子类：⚠️ 必须手动调 super()，Godot 不会帮你调
func _ready() -> void:
	super()                 # ← 忘写这一行，基类的缓存全是 null
	_do_my_own_init()
```

**本项目怎么绕开这个坑**：`MovingObject` **故意不写 `_ready()`**。它需要的东西（子节点引用）在子类里用 `@onready` 各自缓存，基类只提供纯逻辑方法。**基类越少参与生命周期，继承越不容易出错**——这是设计上的取舍，值得你学。

## 3. 核心概念②：**GDScript 没有泛型**（本章最重要的差异）

```csharp
...
if (!canMove && hitComponent != null)
    OnCantMove(hitComponent);       // 玩家撞墙→拆墙；敌人撞玩家→打人
```

调用点：

```csharp
AttemptMove<Wall>(h, v);        // 玩家：我只关心撞到的是不是墙
AttemptMove<Player>(xDir, yDir); // 敌人：我只关心撞到的是不是玩家
```

**一套射线逻辑完成了两件事**：撞墙判定 + 攻击判定，靠泛型区分"撞到的东西是不是我关心的类型"。

### 3.2 Godot 里怎么做

```gdscript
# 基类：只负责"探测 + 移动 + 通知"
func try_move(dir: Vector2i) -> void:
	var blocker := _probe(dir)
	if blocker == null:
		await _slide_to(global_position + Vector2(dir) * Grid.TILE)
	else:
		on_blocked(blocker)        # ← 把决定权交给子类

## 被挡住时调用，子类覆写
func on_blocked(_blocker: Node2D) -> void:
	pass
```

```gdscript
# Player：只关心是不是墙
func on_blocked(blocker: Node2D) -> void:
	if blocker is Wall:
		blocker.damage(wall_damage)
```

```gdscript
# Enemy：只关心是不是玩家
func on_blocked(blocker: Node2D) -> void:
	if blocker is Player:
		blocker.lose_food(player_damage)
```

### 3.3 三种做法的取舍

| 做法 | 优点 | 缺点 |
|---|---|---|
| **`is` 判断**（本项目用） | 简单、直观、无泛型依赖 | 子类要自己写判断 |
| **分组**：`blocker.is_in_group("wall")` | 更"Godot"、不依赖类型 | **字符串硬编码**，拼错静默失效 |
| **信号**：被挡住时 `blocked.emit(blocker)` | 完全解耦 | 小项目里过度设计 |

> **C# 路线可以直接保留泛型**，Godot 的 C# 就是普通 C#：
> ```csharp
> protected async void TryMove<T>(Vector2I dir) where T : Node2D
> ```
> 但我建议**两边都统一用 `is`/`OnBlocked`**，这样你的两份代码能一一对应，读起来不割裂。教程的 C# 版本用 `OnBlocked` + `is`。

## 4. 核心概念③：使用 Tween 补间移动

Godot 的 **Tween** 可以在指定时间内平滑改变节点属性：

```gdscript
func _slide_to(target: Vector2) -> void:
	is_moving = true
	var tween := create_tween()
	tween.tween_property(self, "global_position", target, move_time)   # 从当前值补间到 target，耗时 move_time
	await tween.finished                                              # 等它跑完
	global_position = target                                          # 消除浮点误差，精确落在格点上
	is_moving = false
```

```csharp
// C#
private async Task SlideTo(Vector2 target)
{
    IsMoving = true;
    var tween = CreateTween();
    tween.TweenProperty(this, "global_position", target, MoveTime);
    await ToSignal(tween, Tween.SignalName.Finished);
    GlobalPosition = target;
    IsMoving = false;
}
```

## 5. 核心概念④：为什么本项目不用 `move_and_slide`

Godot 里，**`CharacterBody2D` 的标准移动方式是 `move_and_slide()`**——它需要你设 `velocity`，然后由物理引擎**处理碰撞滑动**（平台跳跃游戏要的就是这个）。

**但我们的游戏不需要它**：

| | 平台跳跃（`move_and_slide`） | 我们的回合制格子游戏（Tween） |
|---|---|---|
| 移动由谁决定 | 物理引擎（撞墙就停、沿墙滑） | **我们自己**（能走就走，不能走就"被挡住"→ 拆墙/攻击） |
| 阻挡怎么办 | 物理自动解算 | **我们主动触发游戏逻辑**（拆墙、扣血） |
| 需要"精确落在格点"吗 | 不需要 | **必须** |

所以我们只要 `CharacterBody2D` 的**"我存在、我有碰撞体、别人射线能打到我"**这层身份，位置由 Tween 直接改。

> **一句话**：`CharacterBody2D` / `StaticBody2D` / `Area2D` 在本项目里**只负责"被查询"，不负责"推进"**。

## 7. 核心概念⑥：输入 —— 事件驱动 + 物理帧处理（**两段式**）

Godot 要**分成两段**，理由是硬的：

| 段 | 做什么 | 为什么必须在这 |
|---|---|---|
| **① `_unhandled_input(event)`** | **记录**玩家按了什么方向（`_pending_dir`） | 输入是**事件**。写在事件回调里，**绝不会漏按键**（哪怕一帧内按了两次） |
| **② `_physics_process(delta)`** | 检查"是我回合吗" → **执行**移动（含射线探测） | **`direct_space_state` 只能在物理帧里访问**（[00 章 §8](./00-核心概念地图.md#8-物理查询使用-intersect_ray)） |

```gdscript
func _unhandled_input(event: InputEvent) -> void:
	if _pending_dir != Vector2i.ZERO:
		return                                  # 已经有一次待处理输入了
	var dir := Vector2i.ZERO
	if event.is_action_pressed("move_left"):
		dir = Vector2i.LEFT
	elif event.is_action_pressed("move_right"):
		dir = Vector2i.RIGHT
	elif event.is_action_pressed("move_up"):
		dir = Vector2i.UP
	elif event.is_action_pressed("move_down"):
		dir = Vector2i.DOWN
	if dir != Vector2i.ZERO:
		_pending_dir = dir
		get_viewport().set_input_as_handled()   # 消费掉这个事件

func _physics_process(_delta: float) -> void:
	if _pending_dir == Vector2i.ZERO or is_moving:
		return
	if GameManager.doing_setup or GameManager.game_ended or not GameManager.players_turn:
		_pending_dir = Vector2i.ZERO            # 不是你的回合 → 丢弃这次输入
		return
	var dir := _pending_dir
	_pending_dir = Vector2i.ZERO
	attempt_move(dir)
```

> **为什么不用 `Input.is_action_just_pressed()` 在 `_process` 里轮询**？也可以，但要注意：`_process` 和 `_physics_process` 的频率不同，而"刚刚按下"是**帧级**概念，混用容易漏。**事件驱动是更稳的写法**，也是 Godot 官方推荐的方向。

## 8. 核心概念⑦：回合制状态机

```
players_turn == true  &&  !enemies_moving
        │
        │ 玩家按方向键（_unhandled_input 收到 → _physics_process 执行）
        ▼
Player.attempt_move(dir)
        ├─ food -= 1；广播 food_changed
        ├─ 播放脚步声
        ├─ try_move(dir) → 同步跑到第一个 await（启动 Tween）
        ├─ GameManager.players_turn = false        ← 交回合
        └─ _check_game_over()
        │
        ▼
GameManager._process 看到 players_turn == false
        └─ _run_enemy_turn()
                ├─ enemies_moving = true           （同步生效 → 当帧就给 _process 上锁）
                ├─ await 计时器(0.1s)
                ├─ 对每个敌人：await 物理帧 → enemy.move_enemy() → await 计时器(move_time)
                └─ enemies_moving = false; players_turn = true
        │
        ▼
玩家又能动了
```

三个"为什么"：

- **`skip_move`（敌人隔回合行动）**：在 `Enemy.attempt_move` 里实现——第一次调用先 `return` 并把 `skip_move` 置 `false`，第二次才真正走。效果是**敌人比玩家慢一半**，玩家才有操作空间。
- **`turn_delay`** 是节奏参数：每回合之间停 0.1 秒，不然敌人看起来是"瞬移"。

### 9.1 `scripts/moving_object.gd`

```gdscript
# GDScript —— scripts/moving_object.gd
class_name MovingObject
extends CharacterBody2D
## 所有"能在棋盘上走一格的东西"的基类。
## 刻意不写 _ready()：基类越少参与生命周期，子类继承越不容易出错。

@export var move_time := 0.1        ## 走一格需要多少秒（越小越干脆）

var is_moving := false

# ---------------------------------------------------------------
#  子类覆写：被挡住时干什么（玩家→拆墙；敌人→攻击）
# ---------------------------------------------------------------
func on_blocked(_blocker: Node2D) -> void:
	pass

# ---------------------------------------------------------------
#  朝 dir 走一格。能走就滑过去，不能走就通知子类。
# ---------------------------------------------------------------
func try_move(dir: Vector2i) -> void:
	var blocker := _probe(dir)
	if blocker == null:
		await _slide_to(global_position + Vector2(dir) * Grid.TILE)
	else:
		on_blocked(blocker)

# ---------------------------------------------------------------
#  射线探测：目标格子里有没有"挡路的东西"
#  必须在物理帧里调用（见 _physics_process）
# ---------------------------------------------------------------
func _probe(dir: Vector2i) -> Node2D:
	var space := get_world_2d().direct_space_state
	var query := PhysicsRayQueryParameters2D.create(
		global_position,
		global_position + Vector2(dir) * Grid.TILE,
		Grid.LAYER_BLOCKING,
	var result := space.intersect_ray(query)
	if result.is_empty():
		return null
	return result["collider"] as Node2D

# ---------------------------------------------------------------
#  分帧平滑插值移动一格（用 Tween，不用手写循环）
# ---------------------------------------------------------------
func _slide_to(target: Vector2) -> void:
	is_moving = true
	var tween := create_tween()
	tween.tween_property(self, "global_position", target, move_time)
	await tween.finished
	global_position = target          # 消除浮点误差，保证精确落在格点上
	is_moving = false
```

```csharp
// C# —— scripts/MovingObject.cs
using System.Threading.Tasks;
using Godot;

public abstract partial class MovingObject : CharacterBody2D
{
    [Export] public float MoveTime { get; set; } = 0.1f;

    public bool IsMoving { get; private set; }

    protected virtual void OnBlocked(Node2D blocker) { }

    protected async void TryMove(Vector2I dir)
    {
        var blocker = Probe(dir);
        if (blocker == null)
            await SlideTo(GlobalPosition + new Vector2(dir.X, dir.Y) * Grid.Tile);
        else
            OnBlocked(blocker);
    }

    private Node2D Probe(Vector2I dir)
    {
        var space = GetWorld2D().DirectSpaceState;
        var query = PhysicsRayQueryParameters2D.Create(
            GlobalPosition,
            GlobalPosition + new Vector2(dir.X, dir.Y) * Grid.Tile,
            Grid.LayerBlocking,
            new Godot.Collections.Array<Rid> { GetRid() });
        var result = space.IntersectRay(query);
        return result.Count > 0 ? result["collider"].As<Node2D>() : null;
    }

    private async Task SlideTo(Vector2 target)
    {
        IsMoving = true;
        var tween = CreateTween();
        tween.TweenProperty(this, "global_position", target, MoveTime);
        await ToSignal(tween, Tween.SignalName.Finished);
        GlobalPosition = target;
        IsMoving = false;
    }
}
```

> ⚠️ **一个 GDScript 的硬坑**：`try_move()` 因为含 `await`，是**异步函数**。**调用它却不用 `await` 时，拿不到返回值**（返回值会被丢弃）。
> 记住这条规则：**GDScript 里"返回值的异步函数"必须 `await` 才能拿到值**。

### 9.4 `scripts/player.gd`

```gdscript
# GDScript —— scripts/player.gd
class_name Player
extends MovingObject

@export_group("数值")
@export var wall_damage := 1                 ## 砸墙一次扣墙多少血
@export var restart_level_delay := 1.0       ## 走到出口后停顿多久再过关

@export_group("音效")
@export var move_sounds: Array[AudioStream] = []
@export var game_over_sounds: Array[AudioStream] = []

@onready var detector: Area2D = $PickupDetector
@onready var anim: AnimatedSprite2D = $AnimatedSprite2D

var food := 0                                ## 本关的 Food（跨关靠 GameManager 传递）
var _pending_dir := Vector2i.ZERO            ## "收到但还没执行"的输入

# ---------------------------------------------------------------
#  生命周期
# ---------------------------------------------------------------
func _ready() -> void:
	food = GameManager.player_food_points     # 读档
	GameManager.spend_food(food)              # 刷新 UI
	detector.area_entered.connect(_on_pickup)
	add_to_group("player")                    # 让敌人能找到我

func _exit_tree() -> void:
	GameManager.player_food_points = food     # 存档：场景重载时必然被调用一次

# ---------------------------------------------------------------
#  输入：事件只"记录"，移动放到物理帧
# ---------------------------------------------------------------
func _unhandled_input(event: InputEvent) -> void:
	if _pending_dir != Vector2i.ZERO:
		return
	var dir := Vector2i.ZERO
	if event.is_action_pressed("move_left"):
		dir = Vector2i.LEFT
	elif event.is_action_pressed("move_right"):
		dir = Vector2i.RIGHT
	elif event.is_action_pressed("move_up"):
		dir = Vector2i.UP
	elif event.is_action_pressed("move_down"):
		dir = Vector2i.DOWN
	if dir != Vector2i.ZERO:
		_pending_dir = dir
		get_viewport().set_input_as_handled()

func _physics_process(_delta: float) -> void:
	if _pending_dir == Vector2i.ZERO or is_moving:
		return
	if GameManager.doing_setup or GameManager.game_ended or not GameManager.players_turn:
		_pending_dir = Vector2i.ZERO          # 不是你的回合，丢掉这次输入
		return
	var dir := _pending_dir
	_pending_dir = Vector2i.ZERO
	attempt_move(dir)

# ---------------------------------------------------------------
#  移动：先扣 1 点 Food，走完就把回合交给敌人
# ---------------------------------------------------------------
func attempt_move(dir: Vector2i) -> void:
	food -= 1
	GameManager.spend_food(food, "-1 ")
	Sfx.play_random(move_sounds)

	try_move(dir)                             # 不 await：同步跑到第一个 await（启动 Tween）就交还
	GameManager.players_turn = false          # ← 回合制的"关"
	_check_game_over()

# ---------------------------------------------------------------
#  撞到墙 → 砸它
# ---------------------------------------------------------------
func on_blocked(blocker: Node2D) -> void:
	if blocker is Wall:
		blocker.damage(wall_damage)
	if anim:
		anim.play("chop")

# ---------------------------------------------------------------
#  被敌人攻击
# ---------------------------------------------------------------
func lose_food(loss: int) -> void:
	food -= loss
	GameManager.spend_food(food, "-%d " % loss)
	_check_game_over()

# ---------------------------------------------------------------
#  踩到东西
# ---------------------------------------------------------------
func _on_pickup(area: Area2D) -> void:
	if GameManager.doing_setup or GameManager.game_ended:
		return
	if area.is_in_group("exit"):
		_go_to_next_level()
	elif area.is_in_group("food"):
		var pickup := area as Pickup
		food += pickup.amount
		GameManager.spend_food(food, "+%d " % pickup.amount)
		pickup.collect()
		_check_game_over()

func _go_to_next_level() -> void:
	GameManager.doing_setup = true            # 冻结回合，别让敌人在转场里继续动
	set_physics_process(false)                # 我自己也不再响应输入
	await get_tree().create_timer(restart_level_delay).timeout
	GameManager.advance_level()               # 关卡 +1 并重载场景

func _check_game_over() -> void:
	if food <= 0:
		Sfx.play_random(game_over_sounds)
		GameManager.end_game()
```

// C# —— scripts/Player.cs
using Godot;

public partial class Player : MovingObject
{
    [Export] public int WallDamage { get; set; } = 1;
    [Export] public double RestartLevelDelay { get; set; } = 1.0;

    [Export] public Godot.Collections.Array<AudioStream> MoveSounds { get; set; } = new();
    [Export] public Godot.Collections.Array<AudioStream> GameOverSounds { get; set; } = new();

    private Area2D _detector;
    private AnimatedSprite2D _anim;

    public int Food { get; private set; }
    private Vector2I _pendingDir = Vector2I.Zero;

    public override void _Ready()
    {
        _detector = GetNode<Area2D>("PickupDetector");
        _anim = GetNode<AnimatedSprite2D>("AnimatedSprite2D");

        Food = GameManager.Instance.PlayerFoodPoints;
        GameManager.Instance.SpendFood(Food);
        _detector.AreaEntered += OnPickup;
        AddToGroup("player");
    }

    public override void _ExitTree() => GameManager.Instance.PlayerFoodPoints = Food;

    public override void _UnhandledInput(InputEvent @event)
    {
        if (_pendingDir != Vector2I.Zero) return;

        var dir = Vector2I.Zero;
        if (@event.IsActionPressed("move_left")) dir = Vector2I.Left;
        else if (@event.IsActionPressed("move_right")) dir = Vector2I.Right;
        else if (@event.IsActionPressed("move_up")) dir = Vector2I.Up;
        else if (@event.IsActionPressed("move_down")) dir = Vector2I.Down;

        if (dir != Vector2I.Zero)
        {
            _pendingDir = dir;
            GetViewport().SetInputAsHandled();
        }
    }

    public override void _PhysicsProcess(double delta)
    {
        if (_pendingDir == Vector2I.Zero || IsMoving) return;
        var gm = GameManager.Instance;
        if (gm.DoingSetup || gm.GameEnded || !gm.PlayersTurn)
        {
            _pendingDir = Vector2I.Zero;
            return;
        }
        var dir = _pendingDir;
        _pendingDir = Vector2I.Zero;
        AttemptMove(dir);
    }

    private void AttemptMove(Vector2I dir)
    {
        Food -= 1;
        GameManager.Instance.SpendFood(Food, "-1 ");
        Sfx.Instance.PlayRandom(MoveSounds);

        TryMove(dir);                       // 不 await：同步跑到第一个 await 就交还
        GameManager.Instance.PlayersTurn = false;
        CheckGameOver();
    }

    protected override void OnBlocked(Node2D blocker)
    {
        if (blocker is Wall wall)
            wall.Damage(WallDamage);
        _anim?.Play("chop");
    }

    public void LoseFood(int loss)
    {
        Food -= loss;
        GameManager.Instance.SpendFood(Food, $"-{loss} ");
        CheckGameOver();
    }

    private void OnPickup(Area2D area)
    {
        var gm = GameManager.Instance;
        if (gm.DoingSetup || gm.GameEnded) return;

        if (area.IsInGroup("exit"))
        {
            _ = GoToNextLevel();
        }
        else if (area.IsInGroup("food") && area is Pickup pickup)
        {
            Food += pickup.Amount;
            gm.SpendFood(Food, $"+{pickup.Amount} ");
            pickup.Collect();
            CheckGameOver();
        }
    }

    private async System.Threading.Tasks.Task GoToNextLevel()
    {
        GameManager.Instance.DoingSetup = true;
        SetPhysicsProcess(false);
        await ToSignal(GetTree().CreateTimer(RestartLevelDelay), SceneTreeTimer.SignalName.Timeout);
        GameManager.Instance.AdvanceLevel();
    }

    private void CheckGameOver()
    {
        if (Food > 0) return;
        Sfx.Instance.PlayRandom(GameOverSounds);
        GameManager.Instance.EndGame();
    }
}

# GDScript —— scripts/enemy.gd
class_name Enemy
extends MovingObject

@export var player_damage := 10              ## 攻击玩家一次扣多少 Food
@export var attack_sounds: Array[AudioStream] = []

@onready var anim: AnimatedSprite2D = $AnimatedSprite2D

var _target: Player
var _skip_move := false                      ## 隔一个回合才行动

func _ready() -> void:
	GameManager.register_enemy(self)         # 登记进本关敌人列表
	_target = get_tree().get_first_node_in_group("player")
	add_to_group("enemy")

## 由 GameManager 每回合调用一次
func move_enemy() -> void:
	if _target == null or not is_instance_valid(_target) or is_moving:
		return

	var diff := Grid.to_cell(_target.global_position) - Grid.to_cell(global_position)
	if diff.x != 0:
		attempt_move(Vector2i(signi(diff.x), 0))     # 先对齐 x
	elif diff.y != 0:
		attempt_move(Vector2i(0, signi(diff.y)))     # x 对齐了再对齐 y

## 隔回合行动：第一次调用跳过，第二次才真的走
func attempt_move(dir: Vector2i) -> void:
	if _skip_move:
		_skip_move = false
		return
	try_move(dir)
	_skip_move = true

func on_blocked(blocker: Node2D) -> void:
	if blocker is Player:
		blocker.lose_food(player_damage)
	if anim:
		anim.play("attack")
	Sfx.play_random(attack_sounds)

```csharp
// C# —— scripts/Enemy.cs
using Godot;

public partial class Enemy : MovingObject
{
    [Export] public int PlayerDamage { get; set; } = 10;
    [Export] public Godot.Collections.Array<AudioStream> AttackSounds { get; set; } = new();

    private AnimatedSprite2D _anim;
    private Player _target;
    private bool _skipMove;

    public override void _Ready()
    {
        _anim = GetNode<AnimatedSprite2D>("AnimatedSprite2D");
        GameManager.Instance.RegisterEnemy(this);
        _target = GetTree().GetFirstNodeInGroup("player") as Player;
        AddToGroup("enemy");
    }

    public void MoveEnemy()
    {
        if (_target == null || !GodotObject.IsInstanceValid(_target) || IsMoving) return;

        var diff = Grid.ToCell(_target.GlobalPosition) - Grid.ToCell(GlobalPosition);
        if (diff.X != 0)
            AttemptMove(new Vector2I(Mathf.Sign(diff.X), 0));
        else if (diff.Y != 0)
            AttemptMove(new Vector2I(0, Mathf.Sign(diff.Y)));
    }

    private void AttemptMove(Vector2I dir)
    {
        if (_skipMove) { _skipMove = false; return; }
        TryMove(dir);
        _skipMove = true;
    }

    protected override void OnBlocked(Node2D blocker)
    {
        if (blocker is Player player)
            player.LoseFood(PlayerDamage);
        _anim?.Play("attack");
        Sfx.Instance.PlayRandom(AttackSounds);
    }
}
```

**关于 AI**：最朴素的**贪心追踪**——先对齐 x，x 对齐了再对齐 y。它不会绕路，所以会被墙卡住。这恰恰是 roguelike 的乐趣（**课后练习**：换成 A\* 寻路。Godot 里可以用 `AStarGrid2D`，内建！）。

> ⚠️ **`Mathf.Sign(0)` 的坑**：C# 的 `Mathf.Sign` 对 0 返回 0（不是 1）。我们已经在调用前判断了 `diff.X != 0`，所以安全。但你要是删掉那个 `if`，就会得到"原地不动"的诡异行为。

## 12. 本章的坑

| 现象 | 原因 |
|---|---|
| 按方向键没反应 | ① Input Map 里动作名拼错（必须和 `move_left` 完全一致）② 忘了 `get_viewport().set_input_as_handled()` 导致事件被别处吃掉 ③ `_pending_dir` 卡住了（检查是不是把它清零的逻辑写在 `return` 之后） |
| 报 `direct_space_state` 相关的错 | 射线查询写在了 `_process` 里。必须在 `_physics_process` |
| 玩家可以走到墙里 | 射线掩码没设对（应该是 `Grid.LAYER_BLOCKING` = 1），或者墙的**图层**没勾 `blocking` |
| 玩家动不了，永远"被挡住" | 射线第一个命中的是**自己**。检查 `exclude` 参数（`[get_rid()]`）有没有写 |
| 食物捡不到 | ① 食物的 `可监控` 关了 ② `PickupDetector` 的 `掩码` 没勾 `pickup` ③ 食物没加进 `food` 分组 |
| `Node not found: "AnimatedSprite2D"` | 子节点名字和 `$AnimatedSprite2D` 不一致，或者你用的是 `Sprite2D` |
| 敌人不动 | ① `add_to_group("enemy")` 没写（不影响，但敌人被注册了吗？检查 `GameManager.register_enemy`）② 玩家没有 `player` 分组 → `_target` 是 `null` ③ 第 1 关本来就没敌人 |
| 敌人一次走两格 | `skip_move` 逻辑写反了 |
| 过关后 Food 归零 | `_exit_tree()` 没写（存档丢了，`GameManager` 还是初始值 100？不对——是**没更新**） |
| 砸完墙还能看到它 | `queue_free()` 是**帧末**生效，同帧内还在。正常现象 |
| 过关后场景重载但关卡号没变 | `advance_level()` 里 `level += 1` 写在了 `reload_current_scene()` 后面（Autoload 不会因为重载而重新 `_ready`，但顺序还是要对） |
| 游戏结束后敌人还在动 | `end_game()` 里要 `set_process(false)`（已经写了）——检查是不是直接改了标志位而没走这个方法 |
