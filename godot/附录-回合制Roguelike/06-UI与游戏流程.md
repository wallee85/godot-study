## 2. 锚点：`Control` 的四个数字

```
Control
├─ anchors（锚点）: left / top / right / bottom     ← 0~1 的比例，"相对父容器"
└─ offsets（偏移）: left / top / right / bottom     ← 像素，"相对锚点"
```

**先看锚点比例，再加像素偏移。**

| 想要的效果 | 锚点预设 | 代码 |
|---|---|---|
| 全屏铺满 | `整个矩形 (Full Rect)` | `set_anchors_preset(Control.PRESET_FULL_RECT)` |
| 左下角小字 | `左下 (Bottom Left)` | `set_anchors_preset(Control.PRESET_BOTTOM_LEFT)` |
| 屏幕正中 | `居中 (Center)` | `set_anchors_preset(Control.PRESET_CENTER)` |
| 顶部横向铺满 | `顶部宽 (Top Wide)` | `set_anchors_preset(Control.PRESET_TOP_WIDE)` |

### 2.1 本项目三个 UI 元素

| 节点 | 类型 | 锚点 | 关键属性 |
|---|---|---|---|
| `BlackOverlay` | `ColorRect` | **整个矩形** | `颜色 = (0,0,0,1)` |
| `LevelLabel` | `Label` | **居中** | `水平/垂直对齐 = 居中`；字号 24；`颜色 = 白` |
| `FoodLabel` | `Label` | **左下** | `偏移 左 = 8, 上 = -28`；字号 12；`颜色 = 浅黄` |

> `FoodLabel` 的 `偏移 上 = -28` 是"**从底部往上 28 像素**"（Godot 里 y 轴向下为正，所以负数 = 往上）。

### 2.2 中文显示（重要提醒）

**Godot 4 的默认字体不含中文字形**，中文会显示成**方框（tofu）**。

本项目的 UI 文字全是英文（`Day 1` / `Food: 100` / `After N days, you starved.`），**不受影响**。但你一旦想在 UI 里加中文（比如"食物：100"），就要：

2. 选中 `Label` → `主题覆盖 → 字体` → 新建 `FontVariation` 或直接拖入 TTF。

## 3. `CanvasLayer`：UI 为什么不会被相机带走

```
Main (Node2D)                    ← 世界坐标系
├─ Camera2D                      相机怎么动，影响的是这一层
├─ Board
└─ LevelUi (CanvasLayer)         ← 独立坐标系：永远贴在屏幕上，不受相机影响
   ├─ BlackOverlay
   ├─ LevelLabel
   └─ FoodLabel
```

| `CanvasLayer` 属性 | 用途 |
|---|---|
| `层级 (layer)` | 数字大的盖在上面（默认 1；世界坐标是 0 层） |
| `跟随视口 (follow_viewport)` | 关掉（默认）就完全不受相机影响 |

## 4. 完整游戏流程（本章真正的主角）

下面这条链，每一环都对应你已经写过的代码。**看懂它，你就真的掌握 Godot 的运行时了。**

### 4.1 从启动到第一关开始

```
Godot 启动
   │
   ▼
【Autoload 阶段】按项目设置里的顺序依次 _ready
   ├─ Sfx._ready           → 造 8 个 AudioStreamPlayer
   └─ GameManager._ready   → set_process(false)      ← 只在游戏启动时跑一次！
   │
   ▼
【加载主场景 main.tscn】把节点树建出来
   │  子节点先 _ready、父节点后 _ready（自底向上）
   ▼
LevelUi._ready()                      ← ① 订阅信号（此时 GameManager 已在，信号能连上）
   ├─ GameManager.level_started.connect(...)
   ├─ GameManager.food_changed.connect(...)
   └─ GameManager.game_over_reached.connect(...)
   │
   ▼
Board._ready()                        ← board_manager 没写 _ready，跳过
   │
   ▼
Level._ready()                        ← ② 父节点最后跑
   ├─ GameManager.begin_level()
   │    ├─ _enemies.clear()
   │    ├─ doing_setup = true          ← 先上锁，别让操作漏进来
   │    ├─ set_process(true)           ← 回合裁判上线
   │    └─ level_started.emit(1)
   │         └─▶ LevelUi._on_level_started(1)
   │              ├─ level_label.text = "Day 1"
   │              ├─ black_overlay.visible = true
   │              └─ await 2 秒 ……（在这里"让出"，本帧结束）
   └─ board.setup_scene(1)             ← ③ 地图在"让出"之后、同一帧内继续执行
        ├─ 铺 10×10 地板与外墙
        ├─ 收集 36 个空格子
        ├─ 撒 5~9 面墙、1~5 个食物
        ├─ 敌人数量 = int(log(1)/log(2)) = 0
        ├─ 放出口 (7,7)
        └─ 放玩家 (0,0)
             └─▶ Player._ready()
                  ├─ food = GameManager.player_food_points (=100)   ← 读档
                  ├─ GameManager.spend_food(100) → food_changed → UI 刷新
                  └─ add_to_group("player")
   │
   ▼
【2 秒后】LevelUi 的 await 恢复
   ├─ black_overlay.visible = false
   └─ GameManager.finish_setup()  → doing_setup = false
   │
   ▼
【可以操作了】
```

> **三个要点**：
> 2. **`await 2 秒` 不会阻塞 `board.setup_scene()`**。`await` 只是让 `_on_level_started` 这个函数"让出"，**事件发射本身立即返回**，所以 `Level._ready()` 紧接着就把地图铺完了。**地图和黑幕是并行推进的**——黑幕盖着地图，玩家在这 2 秒里动不了（`doing_setup`）。
> 3. **Autoload 的 `_ready` 只跑一次**，`begin_level()` 每次关卡开始都跑。别把"每关都要做的事"写进 Autoload 的 `_ready`。

### 4.2 一个回合

```
玩家按 → 键
   │
   ▼
【输入事件阶段】Player._unhandled_input(event)
   ├─ 记录 _pending_dir = Vector2i.RIGHT
   └─ get_viewport().set_input_as_handled()      ← 事件被消费
   │
   ▼
【物理帧阶段】Player._physics_process(delta)
   ├─ 检查：有待处理输入吗？是我回合吗？没在移动吗？
   ├─ 取出 dir，清空 _pending_dir
   └─ attempt_move(RIGHT)
        ├─ food -= 1；GameManager.spend_food(99, "-1 ")
        │     └─▶ food_changed 信号 → UI 显示 "-1 Food: 99"
        ├─ Sfx.play_random(move_sounds)          ← 脚步声
        ├─ try_move(RIGHT)
        │    ├─ _probe(RIGHT)：射线打到了什么？
        │    │    ├─ 空 → _slide_to(目标位置)     ← Tween 开始（同步启动！）
        │    │    └─ 有东西 → on_blocked(它)
        │    │         ├─ 是墙 → wall.damage(1)  → 换破损贴图 / 砸 4 下碎掉
        │    │         └─ 是玩家 → 玩家 lose_food(10)
        │    ├─ play_once("chop")                ← 撞墙时播动画
        ├─ GameManager.players_turn = false      ← ←← 回合制的"关"
        └─ _check_game_over()
   │
   ▼
【渲染帧阶段】GameManager._process(delta)         ← Autoload 的 _process 一直在跑
   └─ 条件成立（players_turn == false 且 !enemies_moving 且 !doing_setup）
        └─ _run_enemy_turn()
             ├─ enemies_moving = true            ← 同步生效 → 下一帧不会重复启动
             ├─ await 计时器(0.1)                 ← 让出
             └─ 对每个敌人（循环）：
                  ├─ await 物理帧                 ← 保证射线查询在物理帧里
                  ├─ enemy.move_enemy()
                  │    ├─ 算出朝玩家的方向（先 x 后 y）
                  │    ├─ skip_move 是 true？→ 跳过这一回合（敌人比玩家慢一半）
                  │    └─ try_move(dir)
                  └─ await 计时器(0.1)
             ├─ enemies_moving = false
             └─ players_turn = true               ← 回合交回给玩家
   │
   ▼
玩家又能动了
```

```
玩家走到出口（PickupDetector 检测到 exit 分组里的 Area2D）
   └─ Player._on_pickup(area)
        └─ area.is_in_group("exit") → _go_to_next_level()
             ├─ GameManager.doing_setup = true     ← 冻结回合，敌人不再动
             ├─ set_physics_process(false)         ← 我自己也不再响应输入
             ├─ await 1 秒
             └─ GameManager.advance_level()
                  ├─ level += 1                     ← 存在 Autoload 里 → 不会丢
                  └─ get_tree().reload_current_scene()
   │
   ▼
旧场景被整体释放：Board / Player / Enemy / LevelUi / Camera2D 全部 queue_free
   └─▶ Player._exit_tree() → GameManager.player_food_points = food   ← 存档！
   │
   （Autoload：Sfx / GameManager 不受影响，也不重新 _ready）
   │
   ▼
新场景加载 → 重新走一遍 §4.1 的流程，但这次 level = 2
   ├─ LevelUi._ready()  → 重新订阅信号（旧的连接已随节点释放自动断开）
   ├─ Level._ready()    → GameManager.begin_level() → 黑幕显示 "Day 2"
   └─ Player._ready()   → food = GameManager.player_food_points      ← 读档，分数保留！
                             敌人数量 = int(log(2)/log(2)) = 1       ← 出现 1 个敌人
```

> **⚠️ 一个必须知道的 Godot 语义**：`reload_current_scene()` / `change_scene_to_file()` 都是**延迟生效**的——它们要等到**当前帧结束**才真正切换。所以调用之后，当前节点**这一帧里还是活的**（`advance_level()` 后面如果还有代码，照样执行）。
> 如果你需要在切换后做事，用：
> ```gdscript
> get_tree().reload_current_scene()
> await get_tree().process_frame     # 等切换真正发生
> ```

### 4.4 游戏结束

```
Food 掉到 0 以下（在 attempt_move 或 lose_food 或 _on_pickup 之后都会调 _check_game_over）
   └─ Player._check_game_over()
        ├─ Sfx.play_random(game_over_sounds)
        └─ GameManager.end_game()
             ├─ game_ended = true
             ├─ doing_setup = true
             ├─ set_process(false)                    ← 回合裁判下线 → 敌人也停了
             └─ game_over_reached.emit(level)
                  └─▶ LevelUi._on_game_over(level)
                       ├─ level_label.text = "After N days, you starved."
                       └─ black_overlay.visible = true
```

> **为什么不销毁 GameManager**：它是 Autoload，销毁了以后就没法重开游戏了，而且别的脚本还在 `GameManager.xxx` 引用它。

## 5. 场景加载的三个关键点（Godot 版）

### 5.1 不需要登记任何场景

**Godot 里所有 `res://` 下的 `.tscn` 都能直接加载**，没有这个坑。

> 代价是：**导出时所有场景都会被打进包里**（Godot 没有"只导出被引用的场景"的优化）。如果场景特别多，可以用导出预设里的「导出时排除」规则。

### 5.2 同步 vs 异步

```gdscript
# 同步（会卡住一帧，但小场景无感）
get_tree().change_scene_to_file("res://scenes/level_2.tscn")

# 异步（加载大场景时用，可以显示进度条）
ResourceLoader.load_threaded_request("res://scenes/level_2.tscn")
while ResourceLoader.load_threaded_get_status(path) == ResourceLoader.THREAD_LOAD_IN_PROGRESS:
	progress_bar.value = ...
	await get_tree().process_frame
var packed := ResourceLoader.load_threaded_get(path) as PackedScene
get_tree().change_scene_to_packed(packed)
```

本项目的一关就是一个 100 节点的场景，**同步重载完全够用**（帧率影响无感）。

### 5.3 Autoload 在重载时的行为

| 问题 | 答案 |
|---|---|
| Autoload 会被销毁吗？ | **不会**。它挂在根节点下，不在"当前场景"里 |
| Autoload 会重新 `_ready` 吗？ | **不会**。整个游戏只 `_ready` 一次 |
| Autoload 里持有的**节点引用**呢？ | **会失效**！旧场景的节点已经被释放了 → 用 `is_instance_valid()` 判断 |
| Autoload 里的**数据**呢？ | **保留**（`level` / `player_food_points` 就是靠这个跨关卡的） |

> **这就是本项目把"每关都要重建的东西"放在场景里、把"跨关的数据"放在 Autoload 里的原因。**
> 如果你在 Autoload 里存了 `var player: Player`，场景重载后它就是**悬空引用**——必须用 `is_instance_valid()` 检查，或者干脆不存（本项目里 `Enemy` 通过 `get_first_node_in_group("player")` **每次关卡开始时重新找**，就绕开了这个问题）。

## 6. 可选增强（做完你就是"能改游戏"的人了）

### 6.1 暂停菜单（Godot 的杀手锏）

```gdscript
# 按 Esc 暂停 / 恢复
func _unhandled_input(event: InputEvent) -> void:
	if event.is_action_pressed("ui_cancel"):
		get_tree().paused = not get_tree().paused
```

然后只要设置 `process_mode`：

| 节点 | `process_mode` | 效果 |
|---|---|---|
| 暂停菜单的 `CanvasLayer` | **`WHEN_PAUSED`** | 只有暂停时才显示、才响应 |
| `GameManager`（Autoload） | **`ALWAYS`** | 暂停时仍能工作（比如处理"返回主菜单"） |
| 其他所有节点 | `INHERIT`（默认） | **`paused = true` 时全部冻结** |

```gdscript
# 暂停菜单脚本
extends CanvasLayer

func _ready() -> void:
	process_mode = Node.PROCESS_MODE_WHEN_PAUSED
	visible = false

func _process(_delta: float) -> void:
	visible = get_tree().paused
```

### 6.2 屏幕震动 / 受击反馈

```gdscript
func shake(amount := 3.0, duration := 0.15) -> void:
	var tween := create_tween()
	for i in 4:
		tween.tween_property(camera, "offset",
			Vector2(randf_range(-amount, amount), randf_range(-amount, amount)), duration / 4)
	tween.tween_property(camera, "offset", Vector2.ZERO, 0.05)
```

## 7. 本章的坑

| 现象 | 原因 |
|---|---|
| UI 不显示 | 忘了放进 `CanvasLayer` 下，或者被相机移出视野（`CanvasLayer` 的子节点才不受相机影响） |
| UI 位置在编辑器里对、运行后偏了 | 锚点没设，只填了「偏移」。**锚点决定"相对什么定位"** |
| 黑幕盖住了字 | `BlackOverlay` 在树上的顺序**在 `LevelLabel` 后面**（同级越靠后越靠上） |
| 中文字显示成方框 | 默认字体没有中文字形（[§2.2](#22-中文显示重要提醒)） |
| 过关后卡住不动 | `advance_level()` 里 `level += 1` 之后忘了 `reload_current_scene()`；或者 `doing_setup` 没被新一轮的 `begin_level()` 重置 |
| 过关后敌人还在动 | `_go_to_next_level()` 里没设 `doing_setup = true` |
| 第 2 关 Food 又变回 100 | `_exit_tree()` 里的存档没写，或者写成了 `GameManager.spend_food(food)`（那只是广播，不是存到持久字段……其实是同一个字段，检查一下是不是顺序问题） |
| 输出面板出现 `Resumed function after await` 之类的提示 | 场景重载时，旧节点上还有**没跑完的 `await`**。逻辑不会崩，但说明有"要等完但对象已经没了"的逻辑 → 用 `is_instance_valid()` 检查，或者别在 `await` 之后依赖场景对象 |
| 暂停后 UI 也冻住了 | 暂停菜单的 `process_mode` 忘了设 `WHEN_PAUSED` |

## 9. 全流程验收：完整跑一遍

现在把整个游戏走一遍，**每一环都对着 §4 的时序检查**：

1. **启动**：黑幕 + `Day 1`，2 秒后消失，`Food: 100`
2. **移动**：每走一步 `-1`，`Food` 标签实时更新
3. **撞墙**：墙换破图，4 次后消失
4. **吃食物 / 苏打**：`+10` / `+20`
5. **饿死**（第 1 关没敌人，一路走到底）：黑幕 `After 1 days, you starved.`
6. **重开项目**（再 `F5`）：应该从头开始（`level` 回到 1）
7. **过关**：走到出口 → 1 秒后 `Day 2`、`Food` 保留、出现 1 个敌人
8. **被敌人打**：`-10`
9. **一路撑到 `Day 4`**：应该看到 2 个敌人（`int(log(4)/log(2)) = 2`）
