# 05 · 动画与音效

---

## 1. 先分清三个词

**本项目用 `AnimatedSprite2D`**，因为像素角色的动画就是"几帧图轮流显示"，用不上时间轴。

**什么时候改用 `AnimationPlayer`**：你要做"UI 面板滑入 + 淡出 + 同时缩放"这种组合动画，或者要动画化非精灵属性（比如把 `Wall` 的 `hp` 从 4 掉到 1）。两者可以共存。

> **两个都是"动画播放器"，区别在"谁驱动"**：
> - `AnimatedSprite2D` → **帧驱动**（播到第几帧）
> - `AnimationPlayer` → **时间驱动**（播到第几秒，可以同时改多个对象的多个属性）

## 2. 使用 AnimatedSprite2D 播放角色动画

```
Idle ──(trigger: playerChop)──▶ Chop ──(无退出条件 / Exit Time)──▶ Idle
Idle ──(trigger: playerHit)──▶ Hit  ─────────────────────────────▶ Idle
```

然后**每一条过渡都要手动配**（`Has Exit Time`、`Transition Duration`、`Conditions`…），漏一条的表现就是"角色一直不回到 Idle"。

Godot 里我们用**两行代码**达到同样效果：

```gdscript
anim.play_once("chop")     # 触发
# 播完自动回 idle —— 靠 animation_finished 信号，而不是"配过渡"
```

```gdscript
func _ready() -> void:
	anim.animation_finished.connect(func() -> void: anim.play("idle"))
```

### 3.1 从序列图切帧

官方素材里 `Player_Idle/Chop/Hit` 是**多帧序列图**。

**Godot 的流程（2 步）**：

1. 双击 `player.tscn` 里的 `AnimatedSprite2D` 节点 → 检查器 `Sprite Frames` → **新建 SpriteFrames** → 点「打开编辑器」（编辑器底部会出现 SpriteFrames 面板）。
2. 面板左边是动画列表（默认有一个 `default`）。点「**添加动画**」改名成 `idle`；然后选中 `idle` → 点「**从精灵表添加帧**」→ 选图片 → 填 `水平 = N`、`垂直 = 1` → 按住 `Shift` 点选要的帧 → 确定。

### 3.2 要做的动画

| 场景 | 动画名 | 帧 | 循环 | 速度(FPS) |
|---|---|---|---|---|
| `player.tscn` | `idle` | Player_Idle（1~2 帧） | ✅ 开 | 4 |
| `player.tscn` | `chop` | Player_Chop | ❌ **关** | 8 |
| `player.tscn` | `hit` | Player_Hit | ❌ 关 | 8 |
| `enemy.tscn` | `idle` | Enemy_Idle | ✅ 开 | 4 |
| `enemy.tscn` | `attack` | Enemy_Attack | ❌ 关 | 8 |

**"循环"在哪里设**：SpriteFrames 面板里，选中某个动画，右边有「**循环**」勾选框。`idle` 勾上、`chop`/`attack` **不勾**——不勾才会发出 `animation_finished` 信号。

**另外**：选中 `AnimatedSprite2D` 节点，把 `Animation → Autoplay` 填 `idle`，这样它一进场景就自己转起来。

> ⚠️ **动画名必须和代码里一致**：代码里写的是 `"idle"` / `"chop"` / `"attack"`（全小写）。**写错了不会报错，只是"动画不播"**——这是本节最常见的坑。

### 3.3 顺手修掉像素抖动

我们的移动是 **Tween 补间**，位置在过渡期间是**小数**（比如 24.37 像素），精灵会落在"两个像素之间"，像素画就会出现**抖动/边缘闪烁**。

修法：`项目设置 → 渲染 → 2D → 将 2D 变换吸附到像素` **打开**。

> **注意**：**不要**为了这个去关掉 `AnimatedSprite2D.centered`——那会把精灵的锚点从"中心"变成"左上角"，**整个棋盘坐标就全错位了**。

## 4. 代码侧：一个小重构（让基类承担动画引用）

[04 章](./04-玩家与敌人-移动与回合制.md) 里 `Player` 和 `Enemy` **各自**缓存了 `anim`，而且用的是 `anim.play("chop")`。现在做两处小改进——**这正好是继承带来的好处**。

### 4.1 把 `anim` 提到基类

在 `scripts/moving_object.gd` 里加一行：

```gdscript
class_name MovingObject
extends CharacterBody2D

@export var move_time := 0.1

@onready var anim: AnimatedSprite2D = $AnimatedSprite2D   # ← 新增：基类统一持有
var is_moving := false

## 播放一次性动画（先 stop 再 play，保证重复触发时能重播）
func play_once(anim_name: StringName) -> void:
	if anim == null:
		return
	anim.stop()
	anim.play(anim_name)
```

```csharp
// C# —— MovingObject 里加
protected AnimatedSprite2D Anim { get; private set; }

public override void _Ready()   // ← ⚠️ 基类写了 _Ready，子类必须 base._Ready()
{
    Anim = GetNodeOrNull<AnimatedSprite2D>("AnimatedSprite2D");
}

protected void PlayOnce(StringName animName)
{
    Anim?.Stop();
    Anim?.Play(animName);
}
```

> **这里有个漂亮的教学点**：
> - **GDScript 侧**用 `@onready`，**不需要覆写 `_ready()`**，所以**子类根本不用管 `super()`**——这就是 [04 章 §2](./04-玩家与敌人-移动与回合制.md#2-核心概念①脚本继承以及-super-陷阱) 说的"基类越少参与生命周期越安全"。

### 4.2 改掉子类里的两处调用

```gdscript
# player.gd：删掉 @onready var anim ...
func on_blocked(blocker: Node2D) -> void:
	if blocker is Wall:
		blocker.damage(wall_damage)
	play_once("chop")          # ← 原来是 anim.play("chop")

func _ready() -> void:
	food = GameManager.player_food_points
	GameManager.spend_food(food)
	detector.area_entered.connect(_on_pickup)
	add_to_group("player")
	anim.animation_finished.connect(_on_anim_finished)      # ← 新增

func _on_anim_finished() -> void:
	anim.play("idle")                                       # 播完一次性动画就回 idle

func lose_food(loss: int) -> void:
	food -= loss
	GameManager.spend_food(food, "-%d " % loss)
	play_once("hit")                                        # ← 新增：被打的动画
	_check_game_over()
```

```gdscript
# enemy.gd
func on_blocked(blocker: Node2D) -> void:
	if blocker is Player:
		blocker.lose_food(player_damage)
	play_once("attack")        # ← 原来是 anim.play("attack")
	Sfx.play_random(attack_sounds)

func _ready() -> void:
	GameManager.register_enemy(self)
	_target = get_tree().get_first_node_in_group("player")
	add_to_group("enemy")
	anim.animation_finished.connect(func() -> void: anim.play("idle"))
```

C# 侧对应地在 `_Ready` 开头补 `base._Ready();`，并把 `_anim?.Play("chop")` 换成 `PlayOnce("chop")`。

> **为什么必须 `stop()` 再 `play()`**：`AnimatedSprite2D` 的 `animation` 属性**只在名字变化时才重置帧计数**。所以连续砸墙时，第二次 `play("chop")` 是在**同一个动画上**——不 `stop()` 就不会从头播。踩过一次就永远记住了。

## 5. 音效：从"一个播放器"升级成"音效池"

### 5.2 音效池实现（把 [04 章 §9.0](./04-玩家与敌人-移动与回合制.md#90-先建一个简版音效-autoload05-章会升级它) 的简版换掉）

```gdscript
# GDScript —— scripts/sfx.gd（整体替换）
extends Node
## 音效池：多个 AudioStreamPlayer 轮流使用，允许音效叠放。

const POOL_SIZE := 8
const DEFAULT_BUS := "SFX"

var _pool: Array[AudioStreamPlayer] = []
var _next := 0

func _ready() -> void:
	for i in POOL_SIZE:
		var player := AudioStreamPlayer.new()
		player.bus = DEFAULT_BUS          # 走独立的 SFX 总线（见 §5.3）
		add_child(player)
		_pool.append(player)

## 从数组里随机挑一个播放（数组为空时静默跳过 —— "还没配音效"也不会报错）
func play_random(streams: Array[AudioStream]) -> void:
	if streams.is_empty():
		return
	play(streams.pick_random())

func play(stream: AudioStream, volume_db := 0.0, pitch := 1.0) -> void:
	if stream == null:
		return
	var player := _pool[_next]
	_next = (_next + 1) % POOL_SIZE       # 轮流用 → 最简单的"抢最旧的那个"策略
	player.stream = stream
	player.volume_db = volume_db
	player.pitch_scale = pitch
	player.play()
```

```csharp
// C# —— scripts/Sfx.cs（整体替换）
using Godot;

public partial class Sfx : Node
{
    private const int PoolSize = 8;
    private const string DefaultBus = "SFX";

    public static Sfx Instance { get; private set; }

    private readonly AudioStreamPlayer[] _pool = new AudioStreamPlayer[PoolSize];
    private int _next;

    public override void _Ready()
    {
        Instance = this;
        for (var i = 0; i < PoolSize; i++)
        {
            var player = new AudioStreamPlayer { Bus = DefaultBus };
            AddChild(player);
            _pool[i] = player;
        }
    }

    public void PlayRandom(Godot.Collections.Array<AudioStream> streams)
    {
        if (streams.Count == 0) return;
        Play(streams.PickRandom());
    }

    public void Play(AudioStream stream, float volumeDb = 0f, float pitch = 1f)
    {
        if (stream == null) return;
        var player = _pool[_next];
        _next = (_next + 1) % PoolSize;
        player.Stream = stream;
        player.VolumeDb = volumeDb;
        player.PitchScale = pitch;
        player.Play();
    }
}
```

> 💡 **另一个选择**：Godot 4.3+ 有 `AudioStreamPolyphonic` 资源，能让**一个**播放器同时叠放多个流。池子的写法更直观，也更容易理解"为什么会丢音效"，所以本教程用池子。

### 5.3 建一条 SFX 音频总线

菜单 `音频 → 音频总线布局`（或底部面板切到「音频」）：

1. 点「添加总线」，改名 **`SFX`**（默认总线叫 `Master`，会自动把 `SFX` 路由到它）。
2. 这样以后做"音效音量滑条"只需要改 `SFX` 总线的音量：
   ```gdscript
   AudioServer.set_bus_volume_db(AudioServer.get_bus_index("SFX"), linear_to_db(0.5))
   ```
   ```csharp
   AudioServer.SetBusVolumeDb(AudioServer.GetBusIndex("SFX"), Mathf.LinearToDb(0.5f));
   ```

### 5.4 音效导入设置

| 设置 | 值 | 为什么 |
|---|---|---|
| `循环` | **关** | 音效是一次性的（背景音乐才开） |
| `压缩 → 模式` | `PCM (16 bit)` 或默认 | 短音效不用压缩，省 CPU |
| `格式` | `16 位` | |

> **长音频（背景音乐）**才建议改成 `Ogg Vorbis`（导入 `.ogg` 文件，Godot 直接支持）。

### 5.5 为什么音效要"随机播一个"

```gdscript
Sfx.play_random(move_sounds)     # 走路：move_1 / move_2 随机
```

**在 Inspector 里配**（把音效拖进数组）：

| 场景 | 字段 | 拖入 |
|---|---|---|
| `player.tscn` | `Move Sounds` | `footstep_1`、`footstep_2` |
| `player.tscn` | `Game Over Sounds` | `gameover` |
| `player.tscn` | `PickupDetector` → 不涉及 | — |
| `food.tscn` | `Collect Sounds` | `eat_1`、`eat_2` |
| `soda.tscn` | `Collect Sounds` | `drink_1`、`drink_2` |
| `wall.tscn` | `Chop Sounds` | `chop_1`、`chop_2` |
| `enemy.tscn` | `Attack Sounds` | `attack_1`、`attack_2` |

> **音效拖给谁，是个设计问题**：
> - **脚步声**归 **Player**（是玩家在走）
> - **吃东西的声音**归 **Pickup**（是食物在"被吃掉"）——所以 `pickup.gd` 里有 `collect_sounds`
> - **拆墙声**归 **Wall**（是墙被砸），这在 [04 章 §9.2](./04-玩家与敌人-移动与回合制.md#92-scriptswallgd) 里已经写好了
> 判断标准很简单：**"这件事发生在谁身上"**。这样任何一方单独被替换/复用，声音都跟着走。

## 6. 运行验证

1. 玩家**站着不动**时应该看到 `idle` 动画在循环。
2. **撞墙**：`chop` 动画播一次，然后**自动回到 `idle`**（如果卡在 `chop` 最后一帧，说明 `animation_finished` 没连上，或者 `chop` 的「循环」忘了取消勾选）。
3. **走动有脚步声**，且**两个声音交替出现**（不是同一个声音重复）。
4. **吃食物/苏打**有不同音效；**拆墙**有拆墙声；**被敌人打**有攻击声 + `hit` 动画。
5. **饿死**时有 game over 音效。
6. 连续**快速撞墙两次**：`chop` 动画**两次都从头播**（这是 `stop()` + `play()` 的效果；去掉 `stop()` 就能看到"第二次不播"）。

## 7. 本章的坑

| 现象 | 原因 |
|---|---|
| 角色不显示动画 | `AnimatedSprite2D` 的 `Sprite Frames` 是空的，或者 `Autoplay` 没填 `idle` |
| 动画不播，但也没报错 | **动画名写错**（`"Chop"` ≠ `"chop"`） |
| 卡在 `chop` 最后一帧 | `chop` 的「**循环**」没取消勾选 → 不会发出 `animation_finished` |
| `animation_finished` 连上了但没回 idle | 信号签名必须**无参**：GDScript 写 `func _on_anim_finished() -> void:`（不要带参数） |
| 连续撞墙第二次不播动画 | 少了 `stop()`（见 §4.2） |
| 音效完全不响 | ① 数组是空的 ② 忘了建 `SFX` 总线（`player.bus = "SFX"` 时找不到总线**会报错**，检查输出面板）③ `Sfx` Autoload 没注册或注册在 `GameManager` 下面 |
| 音效"少了一两个" | 池子太小 + 同一时刻音效太多（把 `POOL_SIZE` 调大） |
| 音效很小/很大 | `volume_db` 是**分贝**：`0` 是原音量，`-6` 是约一半。别填 `0.5`（那几乎听不见） |
| 像素边缘抖 | `渲染 → 2D → 将 2D 变换吸附到像素` 没开 |
| C# 里 `Anim` 是 `null` | 子类覆写 `_Ready()` 时**忘了 `base._Ready()`** |
